## Paper:1




1. Title: SELFEVOLVE: A Code Evolution Framework via Large Language Models
                     
                2. Authors: Shuyang Jiang, Yuhao Wang, Yu Wang

                3. Affiliation: 上海交通大学

                4. Keywords: reinforcement learning, large language models, code generation, SELFEVOLVE

                5. Urls: arXiv:2306.02907v1 [cs.CL]  5 Jun 2023, Github: None

                6. Summary: 

                    - (1):文章的研究背景是增强学习下的代码生成，作者提到了目前大语言模型（LLM）在代码生成上的优秀表现，但是上述方法很大程度上依赖于检索器或知识库，且很难做到一次生成完整的代码；
 
                    - (2):过去的方法较为依赖于外部知识和检索器，这些方法在不同的任务和领域中可能会发生域不匹配，导致结果不尽如人意。作者提出的方法SELFEVOLVE在提取LLM知识的基础上，结合自编写的代码进行调试，相对于之前的检索式方法，SELFEVOLVE在优化性能上具有巨大优势；
 
                    - (3):本文提出了SELFEVOLVE的方法，具体来说是通过两个阶段来实现的：第一个是基于输入prompt或代码生成中的关键词提取知识，生成中间代码，第二个是通过LLMs错误提示，在不进行测试的情况下进行调试。整个过程完成自然语言生成和代码生成的完整自主迭代过程；
  
                    - (4):本文的方法在三个代码生成数据集上进行了实验，包括数据科学代码、软件工程代码和C++到Python的翻译。实验表明，SELFEVOLVE在所有数据集上都比强基线方法具有显著的优势，作者还与其他提示型模型进行了充分分析实验，证明这两个阶段对性能的提升都非常重要。因此作者认为，SELFEVOLVE的方法是具有扩展性的，可以在更高级别的模型上实现，如GPT-4。
7. Methods: 

- (1): 本文提出的SELFEVOLVE方法由两个阶段组成。第一阶段是知识提取及生成，它使用基于输入prompt或代码生成中的关键词提取LLM知识，并将其转换为中间代码，这一部分利用了TransformerXL模型进行自然语言生成。第二阶段是错误调试，它通过在LLMs中提取错误提示，进行中间代码的调试。整个SELFEVOLVE过程完成了自然语言生成和代码生成的完整自主迭代过程。

- (2): 本文使用了三个不同的代码生成数据集进行实验，包括数据科学代码、软件工程代码和C++到Python的翻译。SELFEVOLVE使用这些数据集进行了训练和测试，在三个数据集上都比强基线方法具有显著的优势。

- (3): 作者使用了一些评估指标来评价SELFEVOLVE的性能，其中包括BLEU分数和代码质量得分。SELFEVOLVE在三个数据集上都显著优于强基线方法。

- (4): 本文还对SELFEVOLVE与其他基于提示的模型进行了比较，结果表明，SELFEVOLVE的两个阶段对性能的提升都非常重要。作者认为，SELFEVOLVE的方法是具有扩展性的，可以在更高级别的模型上实现，如GPT-4。





8. Conclusion: 

- (1): 本文提出了SELFEVOLVE：一种基于大语言模型的代码生成框架。它通过自主迭代的方式，结合输入prompt或代码生成中的关键词提取LLM知识，并将其转换为中间代码，最终实现了高质量的代码生成。此方法在三个代码生成数据集上进行了实验均表现出色。

- (2): 创新点：SELFEVOLVE采用单个LLM作为知识提供者和自我反思程序员，同时拥有灵活性和扩展性。性能：此方法在三个数据集上均具有显著优势，并可以适用于其他数据集，而不需要额外的检索器或已设置的数据库。工作负载：SELFEVOLVE利用TransformerXL模型进行自然语言生成，在整个自主迭代过程中减少了人工干预，只需要输入关键词即可生成高质量代码。
