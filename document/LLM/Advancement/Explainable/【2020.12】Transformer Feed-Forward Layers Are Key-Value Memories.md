## Paper:4




1. Title: Transformer Feed-Forward Layers Are Key-Value Memories (用英文输出)

2. Authors: Mor Geva, Roei Schuster, Jonathan Berant, Omer Levy

3. Affiliation: Mor Geva, Jonathan Berant, Omer Levy - Tel-Aviv University Blavatnik School of Computer Science; Mor Geva, Jonathan Berant - Allen Institute for Artificial Intelligence; Roei Schuster - Cornell Tech (标题中包含 Affiliation 中的信息)

4. Keywords: Transformer-based language models, Feed-forward layers, Key-value memories, Natural language processing, Self-attention

5. Url: https://arxiv.org/abs/2012.14913, Github: None

6. Summary:

- (1): 这篇文章研究了 Transformer 模型中的前馈层（Feed-Forward Layers）的作用。尽管前馈层占据了 Transformer 模型参数的三分之二，但其在网络中的作用还未得到深入研究。
- (2): 过去的研究主要集中在自注意力机制的作用分析上，在这篇文章中指出，自注意力层只占了 Transformer 模型参数的三分之一，大部分参数都用于位置相关的前馈层。文章提出前馈层模拟了神经记忆，其中第一个参数矩阵对应 key，第二个参数矩阵对应 value。文章将前馈层的 key 与训练样本中的文本模式相关联，而每个 value 则诱导输出词汇表上的一个分布。 文章表明了学习到的模式是可以解释的，并且较浅的层主要捕获浅层的模式，而更深的层捕获更语义的模式。最后，文章证明前馈层的输出是其 key 和 value 的加权和。在模型的其他层通过残差连接对其进行改进以生成最终的输出分布。
- (3): 文章在 Transformer 模型中提出了前馈层是 key-value memories 的观点，并通过证明示意图和实验验证了前馈层的作用。具体地，将 key 和 value 分别成为前馈层的参数矩阵，并使用输入矩阵与 key 相乘，生成记忆系数，用以计算加权 value 值。通过可解释性实验，文章可以对训练样本中的每个 key 的模式进行解释，并且合成为前馈层的输出分布显示出它们的效果。
- (4): 本文实验结果表明在各种自然语言处理任务上都可以获得相比于基线更好的效果，例如情感分析，自动生成问答等任务。文章中提出的方法全面利用了前馈层的参数来建立 key-value memories，从而提高了模型性能。 
7. Methods:

- (1): 本文研究了 Transformer 模型中前馈层的作用，将其解释为 key-value memories。在此基础上，文章提出了一种新的前馈层解释方法，将第一个参数矩阵视为 key，第二个参数矩阵视为 value。文章认为，前馈层可以模拟神经记忆，其中 key 与训练样本中的文本模式相关联，而每个 value 则诱导输出词汇表上的一个分布。
- (2): 本文将前馈层的输出视为其 key 和 value 的加权和，并进行深入研究。根据文章提出的方法，前馈层的 key-value memories 分别与输入矩阵进行乘法运算，并计算其加权和，作为输出。文章证明，在模型的其他层通过残差连接对前馈层进行改进以生成最终的输出分布。
- (3): 本文通过可解释性实验，对前馈层的 key-value memories 进行了解释。文章将每个 key 与训练数据中的文本模式相关联，并使用合成的输入矩阵作为关键字进行计算。然后，文章生成加权的 value，用于计算前馈层的输出分布。实验结果表明，前馈层的输出可以解释为与训练样本中的特定模式相对应的高概率输出，这些模式在不同层次的前馈层中具有不同的语义信息，更高层次的前馈层可以捕捉到更抽象的语义信息。
- (4): 本文在各种自然语言处理任务中，使用前馈层 key-value memories 的方法，进行了实验验证。实验结果表明，相比于基线模型，该方法可以提高模型在各种任务上的性能，例如情感分析和自动生成问答任务等。





8. Conclusion: 

- (1): 本研究的意义在于提出了 Transformer 模型中前馈层的新解释，即其具有 key-value memories 的作用。通过对前馈层的深入研究，本文揭示了前馈层中的参数可以通过关键词与价值分别进行关联，以建立模型的神经记忆，并且重新审视了目前对 Transformer 背后的网络原理的理解。这对于提高自然语言处理模型的性能，理解模型的可解释性以及网络安全都具有重要的意义。

- (2): 创新点：该研究提出了 Transformer 模型中前馈层的新解释，并揭示了前馈层的本质，为 Transformer 模型背后的网络实现提供了重要的启示。性能：在多种自然语言处理任务中，该研究方法表现出相比基准模型更优秀的实验结果，证明了该方法的有效性。工作量：该研究对 Transformer 模型中前馈层的深入研究需要从参数设计到实验验证的全面工作，形成了全面的研究过程。
