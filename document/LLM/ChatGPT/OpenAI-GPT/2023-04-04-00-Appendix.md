## Paper:3




1. Title: Learning to Summarize with Pre-Training via Backward and Forward Translation


2. Authors: Sascha Rothe, Shashi Narayan, Aliaksei Severyn


3. Affiliation: Sascha Rothe - Facebook AI; Shashi Narayan - Google Research; Aliaksei Severyn - Google Research


4. Keywords: Machine Learning, Natural Language Processing, Text Summarization, Pre-training, Encoder-Decoder Models


5. Urls: Paper - https://arxiv.org/abs/1906.00151, Github - None


6. Summary: 


- (1): 这篇论文的研究背景是文本摘要生成，是建立在深度学习和自然语言处理等领域的基础上，通过使用encoder-decoder的模型实现文本摘要生成任务。


- (2): 过去的方法在文本摘要生成任务中并没有很好地表现，主要原因是在训练数据方面存在不足，本文提出了新的预训练方式来解决这一问题，即通过前向和逆向的翻译来训练模型。本文提出的方法对应用到当前最佳方法上的表现也明显更好。


- (3): 本文的研究方法是基于预训练的encoder-decoder模型。通过预训练，模型能够通过none masking和back translation等技术使模型获得更好的数据进一步训练模型以提高性能。推荐预训练模型时使用多个任务之间的共享设定而不是独立的预训练模型。


- (4): 本文的方法在预训练和微调阶段均可获得最佳结果，并且优于目前现有的预训练方法。在CNN/DailyMail数据集上，本文的方法相对于其他方法提高了大概2个百分点。此外，在重要性评估上，本文的方法明显更好，而且是最先进的方法之一。
7. Methods: 

- (1): 本文的研究方法是建立在深度学习和自然语言处理的基础上，采用encoder-decoder模型实现文本摘要任务。通过预训练，模型可以获得更好的数据，进一步训练模型以提高性能。具体而言，本文使用了前向和逆向的翻译技术对模型进行预训练。在预训练过程中，使用none masking和back translation等技术使模型获得更好的训练数据，从而得到更好的初始参数，有利于后续微调。

- (2): 为了更好地利用预训练模型，本文采用多任务共享设定的预训练方法。通过多任务之间的共享，可以更好地利用预训练模型中学到的知识，并且可以在各个任务上取得更好的性能表现。

- (3): 本文基于CNN/DailyMail数据集进行了实验，并与当前最先进的方法进行了比较。实验结果表明，本文提出的方法在文本摘要任务上表现明显更好，重要性评估也更优，是一个有效的方法。在预训练和微调阶段均可获得最佳结果，并且在CNN/DailyMail数据集上相对于其他方法提高了大概2个百分点。





8. Conclusion:

- (1): 本文提出了一种基于前向和逆向的翻译技术的预训练方式来解决文本摘要生成任务中数据不足的问题，并在多项实验中证明了其效果优异。本文工作的意义在于引入了新的预训练方法，能够有效提高文本摘要任务的性能，为相关领域的研究提供了有益参考。

- (2): 创新点：本文创新性地引入了前向和逆向翻译技术的预训练方法，充分利用了不同任务之间的信息共享，为文本摘要生成任务提供了新思路。性能表现：在多项实验中，本文的方法相对于其他方法提高了大约2个百分点，且在重要性评估上更加优秀。工作量：本文详细描述了预训练和微调的具体实现细节，能够为后续的研究者提供有益的参考。
