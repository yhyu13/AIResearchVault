# 使用无监督聚类训练专家语言模型:一个更有效、更佳形成的方法

## 本文研究的是使用大规模、稀疏的语言模型,使用无监督聚类技术来发现文档集合中的相关文本集群,并在每个集群上训练单独的专家语言模型,通过执行稀疏合集以提高性能。

过去的方法是在所有输入上更新所有参数以进行密集训练,这需要数千个GPU之间的数十亿个参数的同步;BTM方法可以将大量计算分成多个小型专家语言模型,可以消除现有稀疏语言模型的几乎所有通信开销,但它依赖于文档元数据来识别域,而这种监督不总是可用,而本文介绍的CBTM方法使用无监督聚类来发现文本相关性,可以自动发现每个专家的域。

## 本文方法包括两个主要步骤:

使用无监督聚类训练多个专家语言模型,  
并在识别新单词和预测上执行剪枝和动态稀疏性方法。

本文方法通过聚类培训单独的专家,并在测试时组合这些专家获得更好的性能。本文结果表明专家语言模型的性能随着专家数量和训练数据的大小而提高。

### 作者在多个数据集上进行了实验,将其方法与多个密集模型基线进行比较。

结果表明,本文方法在多个数据集上均表现优于现有的密集模型基线,并取得更快的收敛速度,缩短了收敛时间。

**总结:** 本研究的意义在于提出了一种新的方法,使用无监督聚类技术来发现文本相关性,可以自动发现每个专家语言模型的域,从而提高了模型的性能和泛化能力。  
该研究为大规模、稀疏的语言模型的训练提供了一种新的思路和方法。

创新点:本文提出了Clustered Bayesian Topic Model (CBTM)方法,使用无监督聚类来发现文本相关性,可以自动发现每个专家语言模型的域,从而避免了监督信息不全时的问题。

性能:作者通过实验表明,本文方法在多个数据集上均表现优于现有的密集模型基线,并取得更快的收敛速度。  
Workload: 本文的方法可以消除现有稀疏语言模型的几乎所有通信开销,更好地满足了大规模、稀疏的语言模型的训练需求。 另外,通过聚类培训单独的专家,可以有效地加速训练过程,缩短了收敛时间。

1. Title: Scaling Expert Language Models with Unsupervised Domain Discovery（使用非监督领域发现扩展专家语言模型）

2. Authors: Suchin Gururangan, Margaret Li, Mike Lewis, Weijia Shi, Tim Althoff, Noah A. Smith, Luke Zettlemoyer

3. Affiliation: Suchin Gururangan为Meta AI的前工作，其他作者为华盛顿大学、Meta AI和艾伦人工智能研究所的成员。

4. Keywords: Language models; Domain discovery; Expert models; Sparse models; Natural language processing

5. Urls: Paper: https://arxiv.org/abs/2303.14177 ，Github: None

6. Summary:

- (1):本文的研究背景是大型语言模型的训练通常需要更新所有参数，需要千万级的GPU进行参数同步。
- (2):过去的方法使用了分治训练的思想，将全局任务分为若干个小任务分别处理。但是分治模型需要对文本进行手动打标签以实现对训练数据的分离，因此不能够对网络爬虫等大规模文本任务进行处理。本文提出了Cluster-Branch-Train-Merge（C-BTM）算法，使用非监督聚类方法对语料库进行分组，并为每个组训练专家模型。训练后，每个专家模型的输出将被加权处理，生成最终答案。这个方法省略了分治模型中的手动标注环节，并且相对于其他稀疏语言模型来说较为高效。
- (3):实验结果表明，本文提出的C-BTM方法相对于传统的稠密LM和专家LM均有优势。同时，本文将BERT进行裁剪后使用，也获得了相同或更好的性能，证明了该方法的泛化性。
- (4):作者使用多组不同大小的数据集和语言模型进行评估，并在泛化能力和微调任务性能等方面获得了良好的表现。
7. Methods:

- (1): 本文提出了Cluster-Branch-Train-Merge（C-BTM）算法，在语料库上使用非监督聚类方法对文本进行自动分组。首先，将训练数据输入到预训练的语言模型中，得到每个句子的向量表示。然后，通过对这些向量进行聚类，找到具有相似语言特征的文本组。这个方法省略了传统的手动标注，使得对大规模文本任务的处理变得可能。

- (2): 对于每个语言分组，使用一个专家模型对其进行训练。专家模型被定义为训练一个小型的稠密神经网络，其输入是分组内的句子向量，输出是预测下一个单词的概率分布。这个过程包含了两个关键步骤：首先，使用多头自注意力机制来从输入向量中提取上下文信息。然后，将这些信息通过一个前馈网络进行转换并生成概率分布。在训练过程中，使用交叉熵损失函数来指导模型的优化。

- (3): 最后，使用所有的专家模型输出的概率分布来加权得到最终输出。为了更好地利用信息，本文使用了容器模型，将所有的专家模型放在同一个容器中。在最终推断时，使用所有专家模型的前K个预测结果进行加权求和，得到最终输出。

- (4): 为了验证本文方法的有效性，作者在各种任务上进行了实验。实验结果表明，基于C-BTM方法的预训练模型相对于BERT等方法具有更好的泛化性和更高的微调性能。





8. Conclusion: 

- (1): 本文提出了Cluster-Branch-Train-Merge（C-BTM）算法，利用非监督的自动聚类方法将文本分组，使用专家模型进行训练并最终得到优化的概率分布。该方法省略了传统的手动标注，相对其他稀疏语言模型来说较为高效和泛化能力更强。

- (2): 创新点：使用非监督聚类方法进行文本分组，避免了传统的手动标注。性能：实验结果表明，C-BTM方法相对于传统的稠密LM和专家LM均有优势，并对BERT进行裁剪后获得相同或更好的性能。工作量：训练过程中需要对语料库进行分组，并为每个分组训练专家模型，但相对于其他分治方法来说，省略了手动标注环节，因此工作量相对较小。
