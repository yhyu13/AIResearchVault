## Paper:236




1. Title: API-Bank: A Benchmark for Tool-Augmented LLMs（API-Bank: 工具增强型LLM的基准测试）

2. Authors: Minghao Li, Feifan Song, Bowen Yu, Haiyang Yu, Zhoujun Li, Fei Huang, Yongbin Li

3. Affiliation: Alibaba DAMO Academy（阿里巴巴达摩院）

4. Keywords: Large Language Models, Tool-Augmented, Benchmark, API calls, Planning

5. Urls: Paper: arXiv, Github: None

6. Summary:

- (1): 本文研究的背景是目前的大型语言模型(LLMs)还存在一些限制，无法满足人类请求中与实时数据和外部工具交互的需求。因此，我们需要评估LLMs使用工具的有效性和潜在问题。

- (2): 过去的方法不能够很好地处理人类请求，而LLMs使用工具可以有效地进行交互，并可能成为通向人工智能的门户。本文提出了一套基于API的测试套件，能够评估LLMs使用工具的能力，为未来的研究提供基础。

- (3): 本文提出了一套API-Bank的测试套件，其中包括了53个常用的API工具，从而能够全面评估LLMs的能力。实验结果表明，我们的方法能够在一定程度上提高LLMs的处理能力，但是仍然需要进一步的增强。同时，文章作者还进行了错误分析和案例研究，证明了工具增强型LLMs的可行性。

- (4): 本文的测试套件已在大范围的API调用中进行了测试，并获得了令人满意的结果。相较于GPT-3，我们的方法有了一定的提升，但仍然需要继续持续的探索和改进。
7. Methods: 

- (1): 本文的研究方法主要包括三个步骤。首先，从真实API日志中选择出常用的API工具，形成了API-Bank测试套件。然后，利用该测试套件，通过实验评估LLMs的性能。最后，进行错误分析和案例研究，探究工具增强型LLMs的可行性。

- (2): API-Bank测试套件包含53种常见的API调用工具，覆盖了不同领域的文本解析、数据处理、机器学习等方面，能够充分地评估LLMs使用这些工具的能力。

- (3): 实验评估使用GPT-3和经过工具增强的GPT-3在API-Bank测试套件上的表现。实验结果表明，相比于GPT-3，经过工具增强的GPT-3在不同API工具的调用上具有更好的表现，但仍需要继续改进。通过错误分析和案例研究，文章作者确定了工具增强型LLMs在现实应用中的可行性。





8. Conclusion: 
- (1): 本文提出了一套基于API的测试套件API-Bank，用于评估工具增强型LLMs的能力。该测试套件覆盖了53个常见的API工具，通过大量实验验证了增强型LLMs在调用API工具方面的性能和可行性，为未来的研究和应用提供了基础。
- (2): 创新点：本文提出了API-Bank测试套件，提供了充分的常用API工具和调用场景，使得工具增强型LLMs的评估更加直观准确；性能：本文通过实验验证了增强型LLMs在调用API工具方面的性能和可行性，并对其不足进行了分析；工作量：本文提供了大量的实验和数据分析，为后续研究和应用提供了借鉴和参考。总体来说，本文对工具增强型LLMs的应用和发展具有很大的推动作用。
