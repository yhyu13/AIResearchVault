## Paper:118




1. Title: Translating neural signals to text using a Brain-Machine Interface

2. Authors: Janaki Sheth, Ariel Tankus, Michelle Tran, Nader Pouratian, Itzhak Fried, William Speier

3. Affiliation: 第一作者所属机构：加州大学洛杉矶分校物理和天文学系

4. Keywords: Brain-Computer Interface, neural signals, text decoding, LSTM, particle filtering

5. Urls: https://arxiv.org/abs/1907.04265

6. Summary:

- (1): 本文是关于通过大脑机器接口将神经信号转换为文本的研究。
- (2): 既往的研究方法在速度、准确性和普适性方面存在局限性。本研究提出一种直接从神经信号中解码文本的框架。本文的方法能以比现有的BCI通信系统更高的速度和比特率取得鼓舞人心的高准确度，而且不局限于固定的词袋范围，这与以往的研究方法不同。本文的方法为BCI接口在广泛的自然环境下的应用提供了希望。
- (3): 本研究首先从输入信号中分离出不同音素类别信息的频率段，最终形成一个属性集，将其馈送到LSTM中，对每个时间点进行概率分布的辨识，得到被受试者发出的所有音素的概率分布，然后将这些概率与英语语言的先验知识结合起来，通过粒子滤波算法输出对应解码单词的文本。 
- (4): 本研究在6名受试者的数据上展示了高准确度的性能，速度和比特率显著高于现有的BCI通信系统，在输出结果上具有较好的结果，可以支持本文的研究目标。
7. Methods:

- (1): 本研究首先使用颅内深度电极记录受试者在被要求说出单词时的神经信号。 

- (2): 接着，通过频谱分析提取这些信号的频率特征，创建用于分类的特征向量。使用LSTM分类器对每个时间点的所有音素生成概率分布。 

- (3): 然后，粒子滤波算法使用语言模型将这些概率进行时间平滑，以弥补因LSTM复杂性而导致的不连续性。 

- (4): 最后，将解码后的文本与原始口语单词进行比较，输出结果。 

- (5): 实验设计方面，本研究获得了患有癫痫病的患者的数据，并在其颅内深度电极植入后记录他们的神经信号。 

- (6): 特征选择方面，本研究设计实验将信号的频率范围从高Gamma(70-150 Hz)扩展至更大的范围以增强输入信号的区别性。 

- (7): LSTM模型方面，本研究采用双向多层LSTM模型进行解码，由于其能够保持时间间隔的依赖性而得到更高的精度。 

- (8): 语言模型方面，本研究采用概率自动机模型，针对语音信号的规律建立字符和序列之间的映射。





8. Conclusion: 

- (1): 本研究提出了一种直接从神经信号解码为文本的方法，具有广泛的应用前景，尤其对于那些可能由于骨骼肌萎缩、残疾等原因需要依赖BCI进行交流的人群有着重要的意义和应用价值。

- (2): 创新点方面，本文提出直接解码神经信号为文本的方法具有较高的创新点。而且该方法设计中采取了使用状态滤波器进行语言模型的学习，同时也对颅内条状物解码具有鲁棒性，这都为后续研究提供了宝贵的经验。 

- (2): 性能方面，本文方法的比特率、速度等性能均高于现有的BCI通信系统，但其交流准确率仍需提高，且文本解码的工作量仍需进一步探究和优化。

- (2): 工作量方面，本研究的颅内深度电极植入及实验设计较为复杂，但提取的神经信号有效性和实验数据可信度较高，为后续改进该方法提供了有力数据支撑。
