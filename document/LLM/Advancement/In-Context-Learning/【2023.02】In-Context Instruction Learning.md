## Paper:9




1. Title: In-Context Instruction Learning (基于场景的指令学习)

2. Authors: Seonghyeon Ye, Hyeonbin Hwang, Sohee Yang, Hyeongu Yun, Yireun Kim, Minjoon Seo

3. Affiliation: 1KAIST

4. Keywords: In-Context Instruction Learning, Large Language Models, zero-shot task generalization, instruction tuning, reinforcement learning

5. Urls: https://arxiv.org/abs/2302.14691

6. Summary: 

- (1):这篇论文的研究背景是如何通过指令学习，使大型语言模型（LLMs）能够进行零样本任务泛化。

- (2):过去的方法主要是通过模型微调进行指令学习，但需要多次反向传播，效率低下。论文提出了一种基于场景（in-context）的指令学习方法（ICIL），它使用一个固定的提示来评估所有任务，无需重复反向传播。该方法是一种零样本学习方法，通过将任务用于展示数据的组合来构建一个统一的提示，这使得学习器可以推广到未被演示的任务。作者认为，该方法的灵感来自于现实中的学习中的场景，即学习者在在一个环境中学习多个任务的能力。

- (3):ICIL通过拼接交叉任务演示而形成固定提示，从中学习如何遵循指令，然后可以推广到未被演示的任务中。论文中采用一种基于启发式抽样的方法，将多个任务的演示数据组合为一个固定的提示，从而极大地影响了学习绩效。

- (4):ICIL对于预先训练的模型和已经进行指令微调的模型，均能够显著地提高零样本任务泛化性能。论文中，ICIL通过比较实现了一系列现有指令学习方法和ICIL在多个任务上的性能，证明了ICIL的有效性。此外，ICIL在最先进的指令微调基线（text-davinci-003）上的性能提高了9.3%，这表明ICIL的效果与基于指令微调的方法相辅相成。
7. Methods:

- (1): 本文的方法是基于场景的指令学习方法（In-Context Instruction Learning，ICIL）。ICIL首先通过拼接多个任务的演示数据构建一个固定的提示，然后通过该提示来训练学习器。相比于传统的基于微调的指令学习方法，ICIL无需进行多次反向传播，并且可以实现对未被演示任务的泛化。

- (2): ICIL的具体实现过程包括以下几个步骤：首先，从大规模的文本数据库中选择多个任务，并对每个任务提取一组演示数据；其次，基于启发式的方法，将多个任务的演示数据拼接成一个固定的提示，该提示可以被用于所有的任务；然后，通过训练学习器来学习如何遵循指令，并在训练完成后进行零样本任务泛化。

- (3): 论文中使用了两个基准测试集来评估ICIL的性能。一个测试集是基于GPT-2语言模型的指令学习数据集，包括了几个常见的指令学习任务；另一个测试集包括了更广泛的任务，包括了任务描述和演示数据。在评估ICIL的性能时，论文中对比了ICIL与多种指令学习方法，包括了基于微调和基于元学习的方法。





8. Conclusion:

- (1): 本文的贡献在于提出了一种基于场景的指令学习方法（In-Context Instruction Learning，ICIL），并在多个任务上展示了该方法的有效性，可以显著提高模型的零样本任务泛化性能。该方法的灵感来自于现实中学习者在一个环境中学习多个任务的能力，具有一定的现实意义。

- (2): 创新点：ICIL 提出了一种基于场景的指令学习方法，通过拼接多个任务的演示数据构建一个通用的提示，不需要重复反向传播，提高了零样本任务泛化性能。性能：ICIL 在多个任务上的实验结果都优于现有指令学习方法，并且在最先进的指令微调基线（text-davinci-003）上的性能提高了 9.3%。工作量：ICIL 中的启发式抽样方法需要拼接多个任务的演示数据，可能需要更多的数据采集和处理工作。
