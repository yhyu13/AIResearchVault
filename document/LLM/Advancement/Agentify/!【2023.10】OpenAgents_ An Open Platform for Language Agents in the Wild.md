6. Summary:
- (1): The research background of this article is focused on language agents and their potential to perform complex tasks using natural language, especially when developed on large language models.
- (2): Previous language agent frameworks have focused on proof-of-concept agents, neglecting non-expert user accessibility and application-level designs. This article aims to address these limitations by introducing OpenAgents, an open platform for language agents in everyday life.
- (3): The research methodology proposed in this paper is the development of OpenAgents, which includes three agents: Data Agent for data analysis, Plugins Agent with daily API tools, and Web Agent for autonomous web browsing. It offers a web user interface for general users, seamless deployment for developers, and shared components for researchers to build new language agents.
- (4): The methods in this paper enable general users to interact with language agents through a web interface, provide developers with easy deployment options, and offer researchers a platform for developing and evaluating language agents. The performance of OpenAgents supports its goal of facilitating the construction and real-world evaluation of innovative language agents.
7. Methods: 
- (1): 本研究首先关注于语言代理（Language agents）及其在使用自然语言执行复杂任务方面的潜力，特别是在大型语言模型上开发的情况下。
- (2): 之前的语言代理框架主要关注概念验证代理（proof-of-concept agents），忽略了非专业用户可访问性和应用级设计。本文旨在解决这些限制，引入 OpenAgents，这是一个适用于日常生活的语言代理开放平台。
- (3): 本文提出的研究方法是开发 OpenAgents，其中包括三个代理：数据代理（Data Agent）用于数据分析，插件代理（Plugins Agent）提供日常 API 工具，以及网络代理（Web Agent）用于自动网页浏览。OpenAgents提供了一个面向普通用户的 Web 用户界面，为开发人员提供无缝部署选项，并为研究人员提供构建新的语言代理所需的共享组件。

8. Conclusion:

- (1): 本研究的意义是为了将大型语言模型（LLMs）的进展与实际，以用户为中心的应用相结合，推出了一个开源平台OpenAgents。通过构建用于数据分析、工具利用和网页浏览的三种典型应用的代理，OpenAgents展示了其实际实用性。通过 OpenAgents 的开发，我们发现了许多在构建实际应用中独特的挑战。这些挑战突显了从理论设计到完全可操作的代理的复杂性，这些代理满足实际用户需求和交互。通过提供一个全面、透明和可部署的平台，我们的目标不仅是使 LLMs 的巨大潜力超出开发人员和研究人员范围，也是通过接触真实场景促进基础研究，赋予社区利用和完善最新语言代理能力的能力。我们真诚希望 OpenAgents 可以激发并为各种应用和平台铺平道路，简化人类和智能语言代理之间的共生关系。

- (2): 创新点：OpenAgents创新地将大型语言模型与实际应用相结合，通过提供开放平台与用户界面，满足了普通用户、开发者和研究人员的需求。性能：OpenAgents的性能支持其旨在促进创新语言代理构建和实际评估的目标。工作量：在开发OpenAgents过程中，涉及到构建实际应用的独特挑战，需要转化理论设计为完全运行的代理，满足用户需求和交互。
