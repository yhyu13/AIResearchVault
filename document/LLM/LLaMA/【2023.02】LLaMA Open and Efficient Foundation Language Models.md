## Paper:162




1. Title: LLaMA: Open and Efficient Foundation Language Models（LLaMA：开放高效的基础语言模型）

2. Authors: Hugo Touvron, Thibaut Lavril, Gautier Izacard, Xavier Martinet, Marie-Anne Lachaux, Timothee Lacroix, Baptiste Rozière, Naman Goyal, Eric Hambro, Faisal Azhar, Aurelien Rodriguez, Armand Joulin, Edouard Grave, Guillaume Lample

3. Affiliation: Meta AI（Meta AI）

4. Keywords: Language models, LLaMA, Open-access datasets, Performance

5. Urls: Open-access paper url: https://arxiv.org/abs/2302.13971v1 , Github code link: https://github.com/facebookresearch/llama

6. Summary: 

- (1):本文的研究背景是大型语言模型（LLMs）已成为文本任务中十分重要的模型，但部分模型需要使用私有数据，难以公开，这对开放性研究形成了挑战。

- (2):以往的方法主要是通过提高模型规模和训练数据来提升LLM的性能。然而，近期的工作表明，对于给定的计算预算，更好的性能不一定是由最大的模型实现的，而是由训练更多数据的较小模型实现的。本文通过使用公开可用的数据集，训练出了多个范围在7B到65B之间的LLM，从而解决了私有数据对LLM开放性研究的挑战。

- (3):本文提出的研究方法主要是使用公开可用数据集，训练出了一系列先进的LLM，并公布出github开源代码，方便研究人员进行二次开发改进。

- (4):本文提出的LLaMA-13B模型在绝大部分基准测试中的性能都优于GPT-3（175B），尽管它的规模只有后者的十分之一。同时，LLaMA-65B模型的性能也能够与其他最好的大型语言模型（如Chinchilla或PaLM-540B）相提并论。本文的研究方法表现出非常出色的性能，支持了开放公开数据集的性能，有望推动LLM模型的开放性研究进一步发展。
7. Methods: 

本文的方法主要是使用公开可用的数据集，训练出了多个范围在7B到65B之间的大型语言模型（Language models，LLMs），用以解决私有数据对LLM开放性研究的挑战。具体步骤如下：

- (1):使用公开可用的数据集，共涉及7种不同领域，其中包括CommonCrawl、C4、GitHub、Wikipedia、Gutenberg、Books3和ArXiv等，总计1.4T tokens。

- (2):使用基于Transformer架构的LLM，通过改进了的Vaswani等人（2017）的Transformer网络结构，以及减小全连接层的维度、添加归一化层和SwiGLU激活函数等方法对LLM进行训练和优化。

- (3):使用AdamW优化器对LLM进行训练，并采用余弦退火学习率调度器和分布式训练等技术，提升训练速度和效率。

- (4):通过Zero-shot和Few-shot的任务测评，将LLaMA与其他典型的基础语言模型进行比较，包括GPT-3、Gopher、Chinchilla和PaLM等，最终展现了LLaMA的出色性能。





8. Conclusion:
- (1): 这篇论文的意义在于提供了一种开放性研究大型语言模型（LLMs）的新方法，通过使用公开可用的数据集进行训练，可以避免私有数据对LLM开放性研究的影响。同时，该研究方法可以提供较小规模的LLM，却有着与较大规模的LLM相媲美的性能表现，具有很高的实用价值。

- (2): 创新点：本文提出了使用公开可用的数据集训练LLM的方法，可以避免私有数据对LLMs开放性研究的影响，同时大大降低了训练成本。性能表现：本文提出的LLaMA-13B在绝大部分基准测试中的性能都优于GPT-3（175B），尽管它的规模只有后者的十分之一。同时，LLaMA-65B模型的性能也能够与其他最好的大型语言模型（如Chinchilla或PaLM-540B）相提并论。工作量：本文采用了分布式训练和优化技术，可以提高模型训练和优化效率，降低了工作量。
