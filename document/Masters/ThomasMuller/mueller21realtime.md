## Paper:22




1. Title: Real-time Neural Radiance Caching for Path Tracing 

2. Authors: Thomas Müller, Fabrice Rousselle, Jan Novák, Alexander Keller 

3. Affiliation: Thomas Müller (NVIDIA) 

4. Keywords: Path tracing, radiance caching, deep learning, neural networks, real-time rendering 

5. Urls: Paper: https://dl.acm.org/doi/10.1145/3450626.3459812, Github: None 

6. Summary:

- (1): 本文研究了实时路径追踪全局光照问题，包括高阶间接照明的挑战和光辐射量缓存的应用。 

- (2): 过去的方法包括预计算和实时缓存光辐射样本等，但这些方法往往不够灵活且需要大量工程调整。本文提出的基于神经网络的光辐射缓存方法可以处理完全动态的场景，不需要预计算，具有较好的鲁棒性和可预测的性能，且简单易用。 

- (3): 本文提出了一种基于神经网络的在线训练方法，通过渐进地迭代训练更新和缓存访问来模拟无限次反射传输，从而优化模型性能。同时，本文利用现代硬件的流式实现策略，充分利用GPU资源，使得算法可以以实时性能运行。 

- (4): 本文在多种具有挑战性的场景中取得了实时性能和较好的降噪效果，展示了算法的有效性和实用性。实验结果表明，与现有的光辐射缓存技术相比，本文提出的方法在保证效果的情况下具有更好的适用性和灵活性。
7. Methods: 

- (1): 本文提出了一种基于神经网络的光辐射缓存方法，用于处理实时路径追踪中的全局光照问题，包括高阶间接照明的挑战和光辐射量缓存的应用。该方法基于动态场景特征的分析，结合神经网络的优势，建立了一个能够自适应地学习光辐射模型的架构。实时性能的保障得益于机器学习模型的稀疏性，可利用现代GPU的低延时计算和卷积算法的并行实现。

- (2): 本文的主要核心方法是利用基于神经网络的光辐射缓存方法，通过对光线路径的状态信息的编码和整合，建立光辐射量及其梯度的映射关系。在路径追踪算法中，每个像素的求解可以通过一系列的光线传输和采样得到，这也是本算法的计算基础。通过不断累积更新光辐射缓存的权重，可以得到一个不断优化的模型，实现高效的全局照明求解。

- (3): 本文的神经网络光辐射缓存方法可以以在线训练的方式完成自适应性学习，其中结合了一定的训练策略和梯度下降的技巧。具体地，本算法引入了序列式路径追踪技术，以便在每个光线路径上进行强制的累积更新，同时在多个光线路径之间共享权重，利用基于梯度和权重更新的降噪技术进行实时性能和质量的平衡。

- (4): 本文的实验结果证明，该方法能够在多种具有挑战性的场景中取得实时性能和较好的降噪效果。同时，本方法可以在不同的硬件环境下实现高效计算，并且较好地适用于动态场景的处理。本文的方法基于深度学习的光辐射缓存方法为光线追踪算法提供了新的思路和工具，具有一定的创新性和推广价值。





8. Conclusion: 

- (1): 本文提出的基于神经网络的实时光辐射缓存技术为路径追踪全局照明问题提供了新的思路和工具，可以处理实时性能需求下的高质量渲染场景，具有重要的研究价值。 

- (2): 创新点：基于神经网络的光辐射缓存方法、动态场景学习策略、结合流式计算硬件的并行实现等，为全局光照求解提供了新颖的思路和高效的工具。性能：实验结果证明，该方法具有良好的实时性能和较好的降噪效果，并具有较好的灵活性和适用性。工作量：基于深度学习方法的实现需要较大的计算资源，且一定的工程调试工作不可避免。此外，算法对于硬件环境的依赖较强，且不易扩展到分布式集群等更大规模的场景中。
