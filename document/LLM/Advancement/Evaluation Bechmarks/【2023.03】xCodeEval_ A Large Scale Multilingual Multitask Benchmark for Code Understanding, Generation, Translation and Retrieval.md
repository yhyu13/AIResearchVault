## Paper:234




1. Title: XCODEEVAL: A Large Scale Multilingual Multitask Benchmark for Code Understanding, Generation, Translation and Retrieval（XCODEEVAL：用于代码理解、生成、翻译和检索的大规模多语言多任务基准测试）

2. Authors: Mohammad Abdullah Matin Khan, M Saiful Bari, Xuan Long Do, Weishi Wang, Md Rizwan Parvez, Shaﬁq Joty

3. Affiliation: Islamic University of Technology（伊斯兰技术大学）

4. Keywords: Reinforcement learning, Natural Language Processing, Code Generation, Multilingual, Multitask

5. Url: https://arxiv.org/abs/2303.03004 

    Github: None 

6. Summary:

- (1): 本文的研究背景是 AI 中的代码理解、生成、翻译和检索。能够自动生成代码并解决复杂问题是 AI 领域内的一个长期目标。

- (2): 过去的方法采用的是预先训练好的大型语言模型 (Large Language Models, LLMs)，这些方法在生成新的代码、修复错误代码、在编程语言之间进行翻译以及检索相关代码片段方面表现出了令人印象深刻的能力。然而，这些模型的评估通常只在一个或两个特定任务，几个语言，以及局部的粒度 (如函数级别) 上进行评估，并且在许多情况下没有适当的训练数据。 更令人担忧的是，在大多数情况下，生成的代码的评估都只是在词汇重叠方面进行，而不是实际执行；然而，两个代码段的语义相似性（或等效性）仅取决于它们的 "执行相似性"，即能够为给定的输入获得相同的输出。

- (3): 本文提出了一个名为 XCODEEVAL 的执行大规模多语言多任务基准测试，共包含来自约7.5K个不同问题的20M个文档级别编码示例，涵盖了多达 17 种编程语言，并且在执行级别上具有并行性。它包括了总共七个任务，涉及代码理解、生成、翻译和检索，并采用基于执行的评估。同时，本文还开发了一种基于测试用例的多语言代码执行引擎 ExecEval，并提出了一种基于几何平均值和图论原理的新型数据分割和数据选择方案，以平衡多个属性上的数据分布。

- (4): 本文的方法在七个任务中大多数方面都达到了目标，并且在相应任务和语言环境下涵盖了极好的性能和泛化能力，证明了任务的可扩展性和多语言性。因此，这些方法支持了本文的目标。
7. Methods: 

- (1): 本文提出了一个名为XCODEEVAL的执行大规模多语言多任务基准测试，共包含20M个文档级别编码示例（约7.5K个不同问题），覆盖了多达17种编程语言，并且在执行级别上具有并行性。它包括了总共七个任务，涉及代码理解、生成、翻译和检索，并采用基于执行的评估。

- (2): 本文还开发了一种基于测试用例的多语言代码执行引擎ExecEval。ExecEval 使用动态分析技术进行代码解释执行并记录执行日志。它生成覆盖率和路径等统计数据，为基准测试提供了基于执行的评估方法。同时，本文还提出了一种基于几何平均值和图论原理的新型数据分割和数据选择方案，以平衡多个属性上的数据分布。

- (3): 本文在XCODEEVAL基准测试上评估了多个现有的代码相关任务，包括代码理解（函数签名、函数注释、代码输出）、代码生成（函数生成）、代码翻译（跨编程语言的代码翻译）和代码检索（相似代码检索和代码段注释检索）。通过比较几个现有的基线和本文提出的方法，证明了本文方法的有效性和优越性。

- (4): 本文在数据预处理、模型训练和评估、结果分析等方面采用了多种现代机器学习技术，包括深度神经网络模型（如Transformer模型）、自然语言处理技术（如词嵌入、注意力机制、掩码语言模型等）、深度强化学习等技术。通过在多任务多语言基准测试上的实验，证明了本文方法的普适性和鲁棒性。





8. Conclusion:

- (1): 本研究意义在于提出了一个名为 XCODEEVAL 的大规模多语言多任务基准测试，旨在促进 AI 中的代码理解、生成、翻译和检索方向的发展，并且能够为业界提供一种可持续性的基准测试方案。

- (2): 创新点：本文提出了一个基于执行级别的多语言多任务基准测试，并开发了一个基于测试用例的多语言代码执行引擎ExecEval。与现有的基准测试相比，XCODEEVAL 覆盖的编程语言更多，任务类型更加丰富。同时，ExecEval 能够从程序的执行结果中获取语义信息，以更加准确地评估生成的代码的质量。性能：本方法在七个任务中大多数方面都达到了预期，并且在相应任务和语言环境下涵盖了极好的性能和泛化能力。工作量：本方法涉及到数据预处理、模型训练和评估、结果分析等多个方面的工作，需要大量的数据和计算资源的支持。但是，研究者们已经开源了相关资源，方便业界研究者参考。
