## 更新规则

1. **上游驱动**：实验内容严格来自 `01-论文阅读与研究库` 和 `02-算法复现与源码库` 的新增论文/源码
2. **按周归档**：新实验创建后，根据当前日期放入对应周目录
3. **命名规范**：`<序号>-<主题>-实验.md`，序号全局递增
4. **代码要求**：每个实验必须包含可直接运行的 Python 代码块（或明确的外部依赖说明）

---

## 实验 Pipeline

1. **设计**（周末）：AI 辅助设计实验方案
2. **实现**（周末）：编写代码，AI 辅助调试
3. **运行**（周末）：收集结果
4. **分析**（周日）：AI 辅助分析，你得出结论
5. **分享**（周日）：整理成博客或 Notebook
