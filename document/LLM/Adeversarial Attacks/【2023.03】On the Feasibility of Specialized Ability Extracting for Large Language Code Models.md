## Paper:165




1. Title: On the Feasibility of Specialized Ability Extracting for Large Language Code Models (关于大型语言代码模型特殊能力提取的可行性研究)

2. Authors: Zongjie Li, Chaozheng Wang, Pingchuan Ma, Chaowei Liu, Shuai Wang, Daoyuan Wu, Cuiyun Gao

3. Affiliation: 香港科技大学（The Hong Kong University of Science and Technology）

4. Keywords: large language code models, imitation attacks, deep neural models, computer programming

5. Urls: 
Paper: https://arxiv.org/abs/2303.03012v3
Github: None

6. Summary:

- (1):本文研究的研究背景为大型语言代码模型在软件开发方面的应用。
- (2):过去的方法存在人力物力成本高、数据集私有等问题，因此本文提出利用模仿攻击提取大型语言代码模型的特殊能力。作者认为这种方法是可行的，并在文章中提出了不同的查询方案和优化方法以提高攻击效率。
- (3):本文的研究方法是利用模仿攻击数据集来提取大型语言代码模型的特殊能力。作者通过精心设计查询获取目标模型的输出并用于训练模仿模型，提取目标模型的特殊能力，达到特殊需求的目的。
- (4):作者立足于此，系统研究了不同查询方案和不同任务下发动模仿攻击的有效性，提出了优化方法以提高攻击效率，实现了有效的模仿训练过程，并在代码相关任务上取得了较好的表现。作者认为其研究对于提高深度神经模型的安全性具有实质性的帮助。
7. Methods:

- (1): 本文提出了一种基于模仿攻击的方法，用于提取大型语言代码模型的特殊能力。该攻击分为三个阶段：模仿查询生成、响应检查和模仿模型训练，并利用代理数据集生成不同的查询方案。
- (2): 本文设计了三种查询方案：零样本答案、上下文答案和零样本与CoT答案。其中，零样本答案是给定特定的码任务，通过问题头和问题主体生成模仿查询，用于提取模型的特殊能力；上下文答案增加了问题的上下文信息以提高模型的理解能力；而零样本与CoT答案则添加了解释性语句以从模型中提取推理过程。 
- (3): 本文的响应检查方案使用了语言模型、编译器以及静态代码分析工具来确保生成的响应是准确的和有效的，同时保证响应不被 watermark 等干





8. Conclusion: 

- (1): 本文针对大型语言代码模型在软件开发方面的应用问题，提出了一种基于模仿攻击的方法，用于提取大型语言代码模型的特殊能力。该研究对于提高深度学习模型的安全性具有实质性的帮助，在实践应用中具备一定的参考性和借鉴意义。
                     
- (2): 创新点：本文提出了一种基于模仿攻击的方法，用于提取大型语言代码模型的特殊能力，该方法有效提高了模型的性能。性能：在代码相关任务中取得了较好的表现。本文的响应检查方案确保生成的响应是准确的和有效的。工作量：虽然该方法需要大量的数据集，但是通过优化查询方案和训练模型，可以有效提高攻击效率。
