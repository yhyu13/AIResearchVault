#naturallanguageneration #evaluating #languagemodel

Summary:

-   研究了自然语言生成系统(NLG)的评估问题。
-   传统基于参考文本的方法(BLEU、ROUGE、METEOR)在创造性或多样相关性任务中与人类判断不够一致。
-   最近的研究使用大型语言模型(LLMs)作为无参考评估方式,但是这些LLM与人类判断的一致性不够高。 所以,需要更有效、可靠的LLM评估NLG结果方法。
-   本文提出使用GPT-4构建基于链式思考(CoT)和表单填充的NLG评估框架GPTEVAL评估NLG生成文本质量。

Methods:

-   提出基于CoT和表单填充的NLG评估框架GPTEVAL,使用GPT-4作为语言模型结构评估NLG生成文本质量。
-   GPTEVAL是一个基于提示的评估器,包括提示(任务定义和标准)、LLM生成的CoT(描述评估步骤)、打分函数(使用LLM标记概率计算分数)。
-   为不同评估任务,GPTEVAL提示和CoT不同。
-   用任务介绍和标准给出CoT生成评估步骤,使用CoT评估NLG输出。
-   使用GPTEVAL框架在文本概括和对话生成上进行实验,与人类标注的Spearman相关系数为0.514,优于先前方法,证明GPTEVAL用于骨干模型支持目标。
-   对LLM法进行了初步分析,强调LLM可能有文本偏差。

Conclusion:

-   本文意义在于提出GPT-4构建基于CoT和表单填充的NLG评估框架GPTEVAL,并在文本概括和对话生成上进行实验。 这个框架可以更准确可靠评估NLG系统能力。
-   创新点:使用CoT生成描述中间指令,采用字级评估方法填补先前研究空白。 性能:使用GPTEVAL,在总结任务中与人类标注的Spearman相关系数为0.514,优于所有先前方法。 实验注重理论准确性和全面性,准确反映不同NLG系统差异,但没有详细说明处理问题的工作量。

1. Title: GPTEVAL: NLG Evaluation using GPT-4 with Better Human Alignment（使用更好的人机对齐来使用GPT-4进行NLG评价的GPTEVAL）

2. Authors: Yang Liu, Dan Iter, Yichong Xu, Shuohang Wang, Ruochen Xu, Chenguang Zhu

3. Affiliation: Microsoft Cognitive Services Research（微软认知服务研究）

4. Keywords: natural language generation, NLG evaluation, chain-of-thoughts, large language model, GPT-4

5. Urls: https://arxiv.org/abs/2303.16634v1, Github: None

6. Summary:

- (1): 本文主要研究的是自然语言生成系统（NLG）自动化评价的问题。
- (2): 传统的、基于参考文本的度量方法，如BLEU、ROUGE和METEOR，在创造性和多样化的任务中与人类判断的一致性相对较低。最近的研究提出使用大型语言模型（LLMs）作为无参考度量方式，但是这些LLM的框架与人类评价的一致性不够高。因此，有必要探索更有效、可靠的LLMs方法来评估NLG结果。本文提出了使用GPT-4作为大型语言模型体系结构来构建一种基于链式思考（CoT）和表单填充范式的NLG评估框架，名为GPTEVAL，可以对NLG任务中生成文本的质量进行评估。 
- (3): 在实验中，通过只给出任务介绍和评估标准，使用GPTEVAL的CoT生成详细的评估步骤，再加上生成的CoT来评估NLG输出。最后，将评估器输出格式化为表单，并将生成的概率作为评价指标进行细化。 
- (4): 文章使用GPTEVAL框架，对文本概括和对话生成等两个任务进行了广泛的实验，表明GPTEVAL与GPT-4作为骨干模型，在总结任务中与人类标注的Spearman相关系数为0.514，优于所有先前的方法，说明本文方法相对较好地支持了他们的目标。此外，本文还对LLM法进行了初步分析，并强调了LLM法可能存在LMM生成文本的偏见。
7. Methods: 

- (1): 本文提出了一种基于链式思考（CoT）和表单填充范式的自然语言生成系统（NLG）的评价框架——GPTEVAL。该框架使用GPT-4作为大型语言模型体系结构，可以对NLG任务中生成文本的质量进行评估。
 
- (2): GPTEVAL是一个基于提示的评估器，主要包括三个主要组成部分： 一个包含评估任务定义和所需评估标准的提示、由LLM生成的一组中间指令CoT，描述了详细的评估步骤；以及一个打分函数，调用LLM并基于返回标记的概率计算得分。
 
- (3): 对于不同的评估任务，GPTEVAL的提示和CoT具体有所不同。本文通过给出任务介绍和评估标准，使用GPTEVAL的CoT生成详细的评估步骤，并将生成的CoT来评估NLG输出。此外，文章使用GPTEVAL框架，对文本概括和对话生成等两个任务进行了广泛的实验，表明GPTEVAL与GPT-4作为骨干模型，在总结任务中与人类标注的Spearman相关系数为0.514，优于所有先前的方法。 

- (4): 本文还对LLM法进行了初步分析，强调了LLM可能存在文本偏见。





8. Conclusion:

- (1): 这篇文章的意义在于提出了使用GPT-4作为大型语言模型体系结构构建基于链式思考和表单填充范式的NLG评估框架GPTEVAL，并且在文本概括和对话生成等任务中进行了广泛的实验。这个框架可以更准确和可靠地评价自然语言生成系统的性能。
 
- (2): 创新点：本文使用了基于CoT的指令生成中间描述，采用了字级别的评估方法，填补了先前研究中的空白。性能：使用GPTEVAL，在总结任务中与人类标注的Spearman相关系数为0.514，优于所有先前的方法。另一方面，本文的实验结论注重理论的准确性和全面性，即是否能够准确地反映出不同自然语言生成系统的差异，但是文章也没有详细说明他们在处理此类问题时的工作量。
