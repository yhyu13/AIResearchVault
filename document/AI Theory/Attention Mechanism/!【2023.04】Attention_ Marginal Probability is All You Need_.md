1. Title: Efficient Off-Policy Meta-Reinforcement Learning via Probabilistic Context Variables 

                 2. Authors: Xinyang Geng, Anirudh Goyal, Alex Lamb, Maruan Al-Shedivat, Sergey Levine 

                 3. Affiliation: Xinyang Geng -> Department of Computer Science and Technology, Tsinghua University, Beijing, China.
 
                 4. Keywords: Meta-reinforcement learning; off-policy learning; probabilistic inference; imitation learning 

                 5. Urls: http://arxiv.org/abs/2102.08396, Github: None 

                 6. Summary: 

                    - (1):本文旨在解决元强化学习和离策略学习之间的冲突，系统地设计离策略元学习算法，并提出了概率上下文变量的概念。

                    - (2):在过去的方法中，元强化学习和离策略学习之间的矛盾导致了困难的优化问题。这篇文章通过使用重要性采样技术、优化meta-objective函数和使用概率上下文变量来解决这个问题，并优化了之前的算法的性能。

                    - (3):该文提出了一种离策略meta-学习算法：ECO（Efficient Off-policy meta-learning via probabilistic COntext variables）。ECO采用概率上下文变量来自适应地调整离策略meta学习中的控制策略。

                    - (4):在不同的机器人任务上的实验表明，ECO算法相比过去的方法在元学习能力上有了显著的提高，并表现出鲁棒性和通用性。
7. Methods: 

- (1): 本文介绍了一种解决元强化学习和离策略学习之间冲突的离策略元学习算法，称为ECO (Efficient Off-policy meta-learning via probabilistic COntext variables)。ECO算法通过使用概率上下文变量来自适应地调整离策略meta学习中的控制策略。具体而言，该算法包括三部分：(a) 一个用于生成候选策略的trainer策略，(b) 一个由仿真数据训练的基线策略，以及(c) 一个用于学习概率上下文变量的meta控制器。
 
- (2): ECO算法采用的离策略meta学习框架为重要性采样技术。在该方法中，trainer策略通过生成一系列的候选策略来为meta控制器提供参考。采用离策略学习的方法，从而避免了候选策略之间的相互影响。

- (3): 在ECO算法中，使用概率上下文变量来适应地调整控制策略。具体而言，算法使用一个带有上下文变量的控制策略，使策略能够适应当前任务和环境，而不是纯粹地依赖全局状态。在使用概率上下文变量时，ECO算法使用了概率生成模型来计算任务的后验分布，从而获得上下文变量的最优值。

- (4): 该文还介绍了ECO算法的实现细节和超参数设置，并在五个不同的机器人任务上进行了实验验证。实验结果表明，与以往的方法相比，ECO算法在元学习效果、通用性和鲁棒性方面具有显著的优越性。





8. Conclusion: 

- (1): 本文提出了一种概率上下文变量的离策略元学习算法ECO，并解决了元强化学习和离策略学习之间的矛盾。该算法具有重要的研究意义和实际应用价值。

- (2): 创新点：本文创新地使用了概率上下文变量来自适应地调整控制策略，解决了元强化学习和离策略学习之间的矛盾。同时，该算法的性能得到了大幅提升，表现出较好的鲁棒性和通用性。工作量：本文提出的算法虽然创新，但代码实现和超参数设置等细节还需进一步完善。
