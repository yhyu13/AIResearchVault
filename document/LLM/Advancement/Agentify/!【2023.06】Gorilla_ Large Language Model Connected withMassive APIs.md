## Paper:2




1. Title: Gorilla: Large Language Model Connected with Massive APIs

        
        2. Authors: Shishir G. Patil, Tianjun Zhang, Xin Wang, Joseph E. Gonzalez

            
        3. Affiliation: 加州大学伯克利分校 (UC Berkeley)

        
        4. Keywords: Large Language Models, API calls, natural language processing, machine learning
        
         
        5. Urls: Paper: https://arxiv.org/abs/2305.15334v1, Github: None
        
         
        6. Summary:
        
                - (1): 本论文基于大型语言模型，旨在通过 API 调用连接更多的信息，并应用于各种计算任务。
         
                - (2): 已有的方法受到了输入参数准确性和 API 调用误用的限制。因此，本文提出了Gorilla，一种可以准确连接 API 的模型，该模型还与文档检索器相结合，并成功解决了直接提示 LLM 时出现幻觉的问题。因此本方法具有更好的适用性和可靠性，并有望嵌入更大更多的知识库，利用更广泛的外部 API 以完成复杂的计算任务。
                
                - (3): 本文提出的模型基于机器学习和自然语言处理，已经经过高强度的修改与手工调整，在预测 API 的使用时表现良好。结合文档检索，可实现对 API 标准信息的实时更新。
                
                - (4): 运用自己构建的 APIBench 数据集评估 Gorilla 在 HuggingFace、TorchHub 和TensorHub APIs上的表现，结果显示 Gorilla 的表现优于 GPT-4，成功优化了 API 调用中的精度和召回率并减少了幻觉。 Gorilla 具有良好的性能和稳健性，可以很好地支持其在生成 API 调用中的应用目标和任务。
7. Methods: 

- (1): 本文提出了 Gorilla，一种基于大型语言模型和 API 调用连接的方法。首先，作者采集了 TorchHub、TensorFlowHub 和 HuggingFace API 模型之后生成了一个全面的 API 数据集 APIBench。然后，采用自我指导的方式，使用 GPT-4 生成合成训练数据，使用信息检索器协助分类和检索 API，在此过程中调整了 LLaMA-7B 模型的参数。最后，运用 AST 子树匹配评估 Gorilla 方法在 API 呼叫过程中的表现。

- (2): 本文方法具体包括以下步骤：首先，构建三个 API 模型库的数据集 APIBench，然后使用自我指导进行模型训练，生成一个能够准确匹配 API 模型库的联结模型；接下来将检索器应用于联结模型并调整其参数，从而提高联结模型在 API 呼叫中的准确率和召回率；最后，运用 AST 子树匹配评估 Gorilla 方法在 API 呼叫过程中的表现。

- (3): 本文方法的创新点在于引入信息检索器而非简单的模型匹配来帮助 GPT-4 进行 API 分类。另外，文中还提出了一种自我指导的训练方法，可以利用少量的手工修改数据训练出适用于 API 调用的大型语言模型。最后，文中采用 AST 子树匹配评估 Gorilla 方法的效果，可以有效地验证其可行性和性能。





8. Conclusion: 

- (1): 本文的重要意义在于提出了Gorilla方法，可以准确地连接API，从而优化了机器学习领域中的API调用步骤，提高了API调用的精度和召回率，同时具有适用性和可靠性，对于深入研究现有API以及实现更公平和优化的机器学习应用具有很大的价值。
                     
- (2): 创新点：文章引入信息检索器来辅助GPT-4进行API分类，并采用自我指导的训练方法，可以利用少量的手工修改数据训练大型语言模型。表现：Gorilla模型表现优于GPT-4， 可以完成API调用的计算任务，并且在测试时具有良好的适应性。工作量： 模型训练需要调整参数以及合成训练数据，需要一定的时间和投入。
