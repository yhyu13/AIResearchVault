1. Title: LLAVA-PLUS: LEARNING TO USE TOOLS FOR CREATING MULTIMODAL AGENTS (LLAVA-PLUS: 学习使用工具创建多模态智能体)

2. Authors: Shilong Liu, Hao Cheng, Haotian Liu, Hao Zhang, Feng Li, Tianhe Ren, Xueyan Zou, Jianwei Yang, Hang Su, Jun Zhu, Lei Zhang, Jianfeng Gao, Chunyuan Li

3. Affiliation: Dept. of Comp. Sci. & Tech., Institute for AI, BNRist, Tsinghua University

4. Keywords: reinforcement learning, multimodal agents, large multimodal models, vision-language tasks

5. Urls: Paper: https://arxiv.org/abs/2311.05437v1
   Github: None

6. Summary:

- (1): This article focuses on developing a general-purpose multimodal assistant that can follow users' instructions to complete various real-world tasks.

- (2): Existing methods for building multimodal agents have limitations in processing visual information and lack the ability to use different tools effectively. This motivates the need for LLaVA-Plus, which expands the capabilities of large multimodal models and actively engages with image queries.

- (3): The proposed methodology involves training LLaVA-Plus on multimodal instruction-following data, curated to cover tool use examples of visual understanding, generation, and external knowledge retrieval. LLaVA-Plus maintains a skill repository of pre-trained models (tools) and activates relevant tools based on users' inputs.

- (4): LLaVA-Plus outperforms LLaVA in existing capabilities and exhibits new capabilities. It significantly improves tool use performance and enables new scenarios in human-AI interaction sessions, as supported by empirical results.
7. Methods:

- (1): 该方法的核心是开发一个通用的多模态助手，该助手能够根据用户的指令完成各种真实世界的任务。

- (2): 传统的构建多模态智能体的方法在处理视觉信息方面存在局限，并且缺乏有效使用不同工具的能力。这激发了LLaVA-Plus的需求，LLaVA-Plus扩展了大型多模态模型的功能，并积极参与图像查询。

- (3): 提出的方法将LLaVA-Plus训练在多模态指令追踪数据上，这些数据旨在涵盖视觉理解、生成和外部知识检索等工具使用示例。LLaVA-Plus维护了一个预训练模型（工具）的技能仓库，并根据用户的输入激活相关工具。

- (4): LLaVA-Plus在现有功能方面优于LLaVA，并展示了新的能力。它显著提高了工具使用性能，并在人工智能与人类交互会话中实现了新的场景，这得到了实证结果的支持。





8. Conclusion:

- (1): 该论文的意义在于开发了一个通用的多模态助手，能够根据用户的指令完成各种真实世界的任务。

- (2): 创新点：LLaVA-Plus通过扩展大型多模态模型的能力和积极参与图像查询，增强了多模态智能体的工具使用能力。性能：LLaVA-Plus在工具使用性能方面显著优于先前方法，并在人工智能与人类交互会话中实现了新的场景。工作量：文章中细致介绍了数据收集和模型训练的各个环节，确保了研究的可复现性。
