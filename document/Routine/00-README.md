# AI Research Vault — 每周学习 Routine 体系

> **定位**：这是你的 AI 研究学习 Routine 控制塔，模仿 GameDev 的 01-07 体系 + AI-Tasks 主题制。
> 
> **核心原则**：
> 1. **AI 只做脚手架**：AI 提供引导、解释、结构，你来做推导、实验、思考。
> 2. **Routine 固定 > 灵感**：像训练模型一样训练你的学习节奏。
> 3. **证据驱动**：所有判断有论文、代码、数据支撑。
> 4. **可组合**：技能、知识、项目可以跨主题复用。

## 每周执行节奏

### 周一 — 前沿输入日
- 从 [[AI-Tasks]] 选 1-2 个主题
- 执行 `01_Monday/AI-Tasks`：论文预读 + 概念解释 + 面试谈资 + 文献地图
- 输出：[[01-论文阅读与研究库]]

### 周二 — 技能突破日
- 执行 `02_Tuesday/AI-Tasks`：算法推导 + 数学补漏 + 代码骨架 + 测试用例
- 输出：[[02-算法复现与源码库]]

### 周三 — 强制休息日
- 无 AI 任务
- 带研究者视角观察 AI 应用产品
- 记录灵感到 [[07-日记]]

### 周四 — 工程化日
- 执行 `04_Thursday/AI-Tasks`：代码复现 + 调试 + 工具开发 + 性能剖析
- 输出：[[03-实验案例与代码集]]

### 周五 — 复盘日
- 执行 `05_Friday/AI-Tasks`：知识测验 + 周笔记整理 + 下周规划
- 输出：[[06-研究复盘日志]]

### 周末 — 项目实战日
- 执行 `06_Weekend/AI-Tasks`：Demo 设计 + 博客大纲 + 代码 Review
- 输出：[[90-输出milestones]]

### 周日 — 项目收尾日
- 执行 `07_Sunday/AI-Tasks`：集成测试 + 文档补全 + 周复盘
- 输出：[[06-研究复盘日志]]

### 每周 — 外部接触
- 执行 `08_Weekly/AI-Tasks`：发帖 + 社交 + 开源贡献
- 输出：[[06-研究复盘日志]]
