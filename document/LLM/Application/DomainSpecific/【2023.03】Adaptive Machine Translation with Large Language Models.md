## Paper:196




1. Title: Adaptive Machine Translation with Large Language Models (利用大语言模型进行自适应机器翻译)


2. Authors: Yasmin Moslem, Rejwanul Haque, John D. Kelleher, Andy Way


3. Affiliation: Yasmin Moslem隶属于都柏林城市大学（Dublin City University）计算机学院（School of Computing）ADAPT中心；其他作者均隶属于ADAPT中心或其合作学校。


4. Keywords: Machine translation, adaptive, large language model, encoder-decoder, fuzzy matches


5. Urls: Paper: https://arxiv.org/abs/2301.13294v2, Github: None


6. Summary:

- (1):本文研究的背景是自适应机器翻译，旨在通过利用用户反馈、适应先前翻译等手段来提高翻译质量。但实时适应仍是个挑战。

- (2):过去的方法包括领域自适应的机器翻译，如通过专有名词等领域术语进行适应；另外，它们也可以利用相似的翻译来提升翻译性能。但这些方法可能存在数据不足等问题。本文提出了一种使用大语言模型的方法，利用模型的in-context learning能力，训练模型在不需要额外调整的情况下精细进行翻译。此外，文章还针对一些不受支持的语言结合fuzzy matches实现翻译。

- (3):本文所提出的方法是利用大规模语言模型实现in-context learning，不需要再进行微调。在推理时，将一个由翻译对组成的prompt输入到LLM中，以便LLM进行响应的领域和风格特征模拟。文章还提出了一种利用fuzzy matches，即在已有的翻译记忆中实现少量的in-context learning以进一步提高翻译质量。

- (4):本文通过对5个语言对的翻译进行实验，发现该方法下，使用in-context learning的翻译质量可超过encoder-decoder MT系统，尤其是对于以往大规模语言中，此方法的表现非常优秀。同时，在一些语言结合fuzzy matches的情况下，翻译质量还可以进一步提升。
7. Methods:

- (1): 本文提出了一种利用大规模语言模型的方法，实现in-context learning。通过将翻译对输入到大语言模型中，模拟领域和风格特征，不需要再进行微调即可实现精细的翻译。此外，文章还提出了一种利用fuzzy matches实现翻译的方法。

- (2): 作者使用了5个不同的语言对进行实验，比较了使用in-context learning和encoder-decoder MT系统的翻译质量，发现前者表现优秀。同时，该方法在处理以往大规模语言中的翻译方面也表现出色。

- (3): 该方法的优点包括不需要数据预处理、具有较好的领域适应性、能够更好地处理罕见词汇等。缺点是翻译速度较慢，需要处理复杂的计算。





8. Conclusion: 

- (1): 本研究的意义在于提出了一种利用大规模语言模型实现in-context learning的机器翻译方法，并且证明该方法在多个翻译任务上表现优异。同时缺乏支持的低资源语言和不完善的GPT-3分词器也提出了解决方案，可供实际应用中参考。
 
- (2): 创新点方面，本文提出了利用大语言模型实现精细翻译的方法，不需要数据预处理，具有较好的领域适应性和处理罕见词汇等优点，同时在翻译质量上优于encoder-decoder MT系统。性能方面，该方法处理复杂计算导致翻译速度缓慢。工作量方面，本文使用了5个语言对进行实验，支持的语言数量有限，但实验结果非常鼓舞人心。
