## Paper:76




1. Title: Behavior Cloned Transformers are Neurosymbolic Reasoners (具有神经符号化推理能力的行为克隆变压器)

2. Authors: Ruoyao Wang, Peter Jansen, Marc-Alexandre Côté, and Prithviraj Ammanabrolu

3. Affiliation: 第一作者归属于University of Arizona, Tucson, AZ

4. Keywords: Reinforcement learning, neurosymbolic reasoning, behavior cloning, text games

5. Urls: Paper link: arXiv:2210.07382, Github Code link: http://github.com/cognitiveailab/neurosymbolic/

6. Summary:

- (1): 本文研究背景为如何提升交互式人工智能代理的智能水平，并辅助其在文本游戏等语言环境下，完成多步骤推理任务。
 
- (2): 过去的方法往往在复杂的任务推理能力上受到限制，作者因此探索了插入符号模块的技术，以增强模型的推理能力。这种方法能大大提高模型在四个文本游戏难度评估任务中表现，对于算术、导航、排序和常识推理任务，平均表现提高了22%。同时该方法可扩展到新的代理、环境和符号模块，具有很好的可操作性和实用性。

- (3): 本文提出了一种针对文本游戏代理的符号模块注入方法，即将字符指令嵌入到变压器的行动空间中，以便引入符号模块提供的外部知识，获得更好的推理结果。

- (4): 符号模块注入技术提高了模型在四项文本游戏任务中的表现，具有很好的应用价值。同时，该技术在不同复杂性的任务中都有表现优势，表明符号模块注入方法可以搭配现有的深度学习框架进行智能应用。
7. Methods:

- (1): 本文提出了一种针对文本游戏代理的符号模块注入方法，将字符指令嵌入到变压器的行动空间中，以引入符号模块提供的外部知识，以获得更好的推理结果。

- (2): 符号模块注入技术通过注入行为克隆的操作，将符号模块的知识注入到原来的深度强化学习模型中，以提高模型在四个文本游戏难度评估任务中的表现。

- (3): 对于所提出的方法，本文以四个文本游戏为基准环境，对比了常规深度强化学习模型和模型注入符号模块后的性能，结果表明新方法具有更强的推理能力，并可扩展到新代理、新环境和符号模块，有很好的可操作性和实用性。 

- (4): 符号模块在本文中包括知识基础模块、导航模块、算术模块和排序模块，其中知识基础模块的注入中操作最多，而排序模块最少。本文还介绍了用于实验的行为克隆代理和深度强化学习代理。





8. Conclusion:

- (1): 本研究的意义在于提供了一种用于增强智能代理多步骤推理能力的新方法，在文本游戏等语言环境下取得了显著的效果，对于进一步拓展代理在复杂交互环境中的应用具有一定的借鉴意义。

- (2): 创新点：本文提出了使用符号模块注入技术提升代理推理能力的方法，通过将符号模块的知识注入到现有模型中，实现模型的增强。性能：实验结果表明，符号模块注入技术可以显著提高模型在文本游戏等难度评估任务中的表现，平均提高了22%。工作量：本文所提出的方法具有较高的可操作性和实用性，可以扩展到不同代理、环境和符号模块，但仍需考虑符号模块在实践中的有效性和可行性。
