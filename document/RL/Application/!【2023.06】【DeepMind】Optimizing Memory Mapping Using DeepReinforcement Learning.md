6. Summary: 

- (1): 本文针对资源调度和分配在许多高影响系统中扮演着重要角色的问题进行研究。在特定于机器学习的这个领域中，通过优化机器学习编译过程中的内存映射问题，找到更优的解决方案可以节省时间和资源，减少设备的损耗，甚至可能提高碳排放方面的效果。

- (2): 目前的方法通常是通过编译器中一系列专家设计的基于规则的启发式策略来解决内存映射问题，但这些方法往往只能覆盖一般情况，会出现次优的结果。本文提出使用深度强化学习来解决内存映射问题，利用搜索和学习的能力来找到更优的映射方案。

- (3): 本文提出一种单人游戏——MMapGame，将内存映射问题作为强化学习问题来处理。该游戏接收程序的指令序列作为输入，将输出或操作分配到限制大小的、快速内存（例如TPUv4上的CMEM）或较大但速度较慢的内存（例如TPUv4上的HBM）中，以优化程序的总执行时间。对于每个输出或操作，玩家需要决定是否将其分配到快速内存，以及是否要安排数据转移。决策需满足硬件限制，例如快速内存的大小或内存之间的数据传输带宽。通过每个缓冲区的决策，游戏逐步构建出内存映射问题的解决方案。文中提出的强化学习代理MMap-MuZero是MuZero的扩展，并结合了一个用于理解内存分配问题结构的革新性表示网络，以及一种旁路机制，以处理不可行的状态。

- (4): 文中提出的方法在TPUv4i ML加速器上，该加速器功能的scratchpad快速内存为CMEM，主内存为HBM，优化了运行在实际ML工作负载上的内存映射。将该方法与XLA（Accelerated Linear Algebra）编译器的默认设置进行比较，发现该方法能够改善60个程序中的33个，独立使用时平均加速比为0.59％，最大加速比为87％。其在AlphaTensor矩阵乘法模型方面也实现了5.78％的内存映射加速。提供了一组调查研究，以进一步深入了解其性能。最终，结合当前生产启发式策略，MMap-MuZero-prod是一个混合代理，能够将平均执行时间提高4.05％。需要注意的是，即使是单个百分点的提升，也能有效节省大量资源。
7. Methods:

- (1): 本文提出了一种使用深度强化学习来解决内存映射问题的方法。该方法使用MMapGame作为对话框架，将内存映射问题转化为强化学习问题。具体而言，将编译器编译后生成的指令序列输入给MMapGame供其做决策，包括将输出或操作分配到快速内存或较慢的内存中，以及是否进行数据转移等。通过每个缓冲区的决策，游戏逐步构建出内存映射问题的解决方案。

- (2): 为了使MMapGame更加完整，本文引入了一个用于理解内存分配问题结构的革新性表示网络Representation Network。该网络使用神经网络框架，将内存分配问题转换为图像表示，并以此将内存映射问题的复杂性降至可控制的范围内。同时，为了提高决策效率，本文还引入了一种旁路机制Sideband Mechanism，能够处理不可行的状态，并消除与预测无关的决策。

- (3): 为了强化求解过程，本文还使用了MuZero，即一种强化学习代理，结合搜索和学习，可以寻找最优解决方案。具体而言，MuZero将搜索、策略评估、值函数评估和环境模型预测四个任务结合在一起，构建出内存映射问题的求解模型。

- (4): 通过将本文提出的方法应用于在TPUv4i ML加速器上的内存映射问题，发现该方法能够改善60个程序中的33个，以平均加速比0.59%及最大加速比87%提高程序执行效率。测试结果表明，MMap-MuZero-prod是一个混合代理，具有优秀的性能。





8. Conclusion: 

- (1): 本文提出了一种使用深度强化学习来解决内存映射问题的方法，这在机器学习编译过程中是具有很大意义的，可以有效地节省时间和资源，减少设备损耗，降低碳排放。该方法通过MMapGame将内存映射问题转化为强化学习问题，利用了深度强化学习的搜索和学习能力来找到更优的解决方案。这是一项具有较高实际应用价值的研究成果。

- (2): Innovation point: 本文提出了一种使用深度强化学习来解决内存映射问题的新方法，能够显著提高程序执行效率。此外，该方法引入了Representation Network和Sideband Mechanism等创新机制，使得强化学习代理能够更加高效地处理内存映射问题。

Performance: 本文使用的MMap-MuZero 方法在TPUv4i ML加速器上得到了广泛的测试。测试结果表明，该方法能够显著提高程序执行效率，改善60个程序中的33个，以平均加速比0.59%及最大加速比87%提高程序执行效率。最终，结合当前生产启发式策略，MMap-MuZero-prod是一个混合代理，能够将平均执行时间提高4.05％。性能测试表明，该方法具有较高的实用价值。

Workload: 本文提出的MMapGame作为对话框架，将内存映射问题转化为强化学习问题，结合Representation Network和Sideband Mechanism等新机制，使得强化学习代理能够更加高效地处理内存映射问题，同时也为解决类似问题提供了一种新颖的思路和方法。但是，该方法目前仅在TPUv4i ML加速器上进行了测试，有待在更广泛的环境中进行验证。
