## Paper:3




1. Title: Empower Large Language Model to Perform Better
(赋能大型语言模型实现更好的表现)

2. Authors: Zezhong Wang, Fangkai Yang, Pu Zhao, Lu Wang, Jue Zhang, Mohit Garg, Qingwei Lin, Dongmei Zhang
(王泽中, 杨放凯, 赵璞, 王璐, 张崛, Mohit Garg, 林庆威, 张东梅)

3. Affiliation: The Chinese University of Hong Kong 
(香港中文大学)

4. Keywords: Large Language Model, Industry-specific Question Answering, Dataset, Model Interaction, Model Fusion (大型语言模型，行业特定问答，数据集，模型交互，模型融合)

5. Urls: Paper: arXiv:2305.11541v1 [cs.CL] Github: None 

6. Summary: 

- (1):本篇论文的研究背景是大型语言模型（LLM）在产业特定场景中表现一般，因为它没有特定的知识。 

- (2):过去的方法主要是采用检索方法和外部模块提取领域特定知识，但这些方法都具有一些局限性。本文提出了一种新的模型交互范式，用于实现在不熟悉的领域特定任务上提升LLM的表现。 

- (3):本文提供了一个领域特定的问答（QA）数据集（MSQA），包含了有关Microsoft产品和客户遇到的IT技术问题的云行业特定QA知识，适合评估旨在改进LLM领域特定能力的方法。作者提出了一种新的模型融合框架，将检索方法与LLM相结合，从而获得更好的性能。 

- (4):作者通过实验表明，他们所提出的方法的性能优于普通LLM与检索方法的组合。他们的方法旨在提高LLM在特定领域任务的性能，达到了他们的目标。
7. Methods: 

- (1): 本文提出一种新的模型交互范式, 其中包括两个关键步骤: 获取具有对齐知识的领域特定模型和将生成的领域特定知识提供给LLM，以帮助改进LLM在特定领域任务上的表现。

- (2): 作者通过使用公开Azure文档数据进行预训练小型语言模型，构建Microsoft Azure的知识库，并通过instruction tuning方式将领域特定知识融入到小型语言模型中，以使其具有领域特定知识。

- (3): 为了便于instruction tuning，作者从MSQA数据集的训练集中构建指示。每个指示由一个三元组组成，包括一个指示提示、一个输入查询或语句和一个相应的响应。作者提出了一种新的模型融合框架，通过将检索方法与LLM相结合，以获得更好的性能。





8. Conclusion:

- (1): 本篇论文的意义在于提出了一种新的模型交互范式，能够帮助大型语言模型 (LLMs) 在产业领域特定场景中表现更好，成功地增强LLMs在领域特定任务中的性能。

- (2): 
创新点：本文提出了一种新的模型交互范式，该范式将检索方法与LLMs相结合，从而成功获得更优秀的性能，同时给出了一种evaluation metrics，方便领域特定任务的评估。

性能：作者使用领域特定的MSQA数据集对其方法进行实验，并相较于普通LLMs与检索方法的组合等方法，证明了他们所提出的方法的显著优于对照组，表现出更好的性能。

工作量：论文提供了一个领域特定的问答（QA）数据集（MSQA），包含了有关Microsoft产品和客户遇到的IT技术问题的云行业特定QA知识，适用于评估旨在改进LLMs领域特定能力的方法。同时为了便于instruction tuning，作者从MSQA数据集的训练集中构建指示。总的来说，作者较为详细地描述了所使用的数据集、方法和指标，使得研究可重复性得到较好的保证。
