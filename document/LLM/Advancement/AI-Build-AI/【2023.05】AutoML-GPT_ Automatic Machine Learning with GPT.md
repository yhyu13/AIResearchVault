## Paper:5




1. Title: AutoML-GPT: Automatic Machine Learning with GPT (AutoML-GPT：基于GPT的自动机器学习)

2. Authors: Shujian Zhang, Chengyue Gong, Lemeng Wu, Xingchao Liu, Mingyuan Zhou（张书剑，巩成越，吴乐萌，刘行超，周明远）

3. Affiliation: The University of Texas at Austin（得克萨斯大学奥斯汀分校）

4. Keywords: AutoML, GPT, Machine learning, Large language models, Prompt generation （自动机器学习，GPT，机器学习，大语言模型，提示生成）

5. Url: https://arxiv.org/abs/2305.02499 Github: None

6. Summary:


- (1):本文的研究背景是自动机器学习与大语言模型的相互结合。使用大语言模型可以生成任务导向的提示并自动优化模型，从而减少人工设计模型的时间和精力成本，提高机器学习的效率。

- (2):过去的机器学习方法往往需要大量人力进行模型选择、优化算法和超参数优化等，这些都带来了大量的时间和成本。本文提出的 AutoML-GPT 方法就是使用大语言模型 GPT 作为桥梁自动进行数据处理、模型构建和超参数选择。该方法具有可扩展性和广泛适用性，能够有效地解决自动机器学习中的多种问题。

- (3):本文提出的AutoML-GPT方法主要涉及三个部分：数据卡片生成、模型卡片生成和AutoML搜索。在数据卡和模型卡片中，利用领域专家的知识构建自然语言描述任务和数据。然后，在搜索层次中，利用强化学习和自适应化策略直接优化数据处理和模型架构的超参数。

- (4):本文通过实验评估了AutoML-GPT方法在计算机视觉和自然语言处理等领域多个数据集上的性能。结果表明，AutoML-GPT方法可以取得很好的性能表现，验证了该方法的效力。
7. Methods:

- (1): 本文的方法主要包括三个步骤：

  - 第一步是数据卡片（data card）生成。在这一步中，利用大语言模型 GPT 生成自然语言任务和数据的文本描述，并将其转换为可以进行数据预处理和建模的规范格式；

  - 第二步是模型卡片（model card）生成。在这一步中，同样利用 GPT 生成自然语言对于模型的描述，然后将该描述转化为可实现的模型结构；

  - 第三步是 AutoML 搜索。在这一步中，通过强化学习和自适应化策略自动优化数据处理方法和模型架构的超参数。

- (2): AutoML-GPT 方法具体实现时采用了以下两个模块：

  - 预处理模块。该模块主要处理原始数据并将其转化为可进行建模的格式。在该模块中，使用 GPT 生成数据卡片，并自动进行数据的预处理和清洗。该模块的目标是使原始数据符合模型训练的要求，从而达到最优性能。

  - 自适应学习模块。该模块主要实现了模型卡片的生成，即根据 GPT 生成的模型描述，自动选择和优化模型的结构和超参数。该模块采用强化学习算法进行模型搜索，以最大化模型的性能，并通过适当的正则化策略来避免过拟合。

- (3): 本文的实验主要分为两个方向：计算机视觉和自然语言处理。在计算机视觉领域，实验数据集包括 CIFAR-10 和 CIFAR-100；在自然语言处理领域，实验数据集包括 GLUE 和 SuperGLUE 等。实验结果表明，AutoML-GPT 方法可以在这些数据集上实现与人类专家相当甚至更好的性能表现。





8. Conclusion:

- (1): 本研究的意义在于：将自动化机器学习与大语言模型相结合，使用自然语言生成任务提示和自动化模型优化，从而消除了人工设计模型的时间和精力成本，并提高了机器学习的效率和性能表现。

- (2): 创新点：通过使用大语言模型 GPT 实现自然语言生成任务提示和模型优化，消除了人工设计模型的痛点。性能：AutoML-GPT在多个领域数据集上表现优秀，能够实现与人类专家相当甚至更好的性能表现。工作量：该方法能够自动进行模型选择、优化算法和超参数优化等，大大减少了人工介入和工作量。
