1. Title: GPT-4 Technical Report (GPT-4技术报告)

2. Authors: OpenAI

3. Affiliation: OpenAI (OpenAI)

4. Keywords: Large Language Models, Artificial Intelligence Safety, Anticipatory Governance, NLP, GPT-4

5. Urls: Paper Link: None, Github Code Link: None

6. Summary:

- (1): 本文针对大型语言模型（LLMs）在多个领域的应用，探讨了在GPT-4中发现的最新安全挑战和其存在的高风险行为。此外，文中还总结了OpenAI为预防这些安全隐患所进行的安全性措施，强调了提前规划和治理的重要性。

- (2): 本文在历史方法的基础上，针对GPT-4模型的安全挑战和高风险行为，提出了一些解决方案。同时，文中也强调了这些解决方案的脆弱性，以及提前规划和治理的必要性。

- (3): 本文提出了一种安全保障方案，其中包括测量、模型层级的更改、产品和系统层级干预（如监测和政策）以及对外专家的参与。

- (4): 该方法在某些方面具有缺陷并且局限性较大，但可以避免某些不当使用，并减少了不正确结果的产生。因此，这种安全保障方案可以强化GPT-4模型的安全性，提升其在各个领域的应用价值。
7. Methods:

- (1): 本文通过选取最近的官方历年考试或第三方出版的2022-2023年的学习材料中的模拟考试进行训练数据的筛选，以检测模型中是否存在考试题目，同时报告了模型的训练数据的检查结果。

- (2): 本文针对GPT-4模型的安全挑战和高风险行为，提出了一些解决方案。对于多项选择题，使用few-shot prompt，对于开放式题目，将问题提示作为简单的指令式请求，随后在推理和表述的基础上生成回答，并采用方法得分标准评估答案质量。

- (3): 本文提出了一种安全保障方案，包括测量、模型更改、产品和系统干预以及对外专家的参与，能够避免不当使用和减少错误结果的产生。

- (4): 本文还进行了多项选择题和开放式题目的打分工作，将多项选择题得分转换为官方积分数，并采用重新标准化方法计算AP考试的总分和排名，以及改进了缺少图像信息的答案打分方法，同时还提供了部分小样本的任务，借此测量和说明GPT-4的能力。





8. Conclusion: 

- (1): 本文是一份针对GPT-4模型的技术报告，旨在探讨其在多个领域的应用并分析其存在的安全挑战，提出了相应的安全性措施。该研究对进一步推动大型语言模型的发展与应用具有重要的实践意义。
