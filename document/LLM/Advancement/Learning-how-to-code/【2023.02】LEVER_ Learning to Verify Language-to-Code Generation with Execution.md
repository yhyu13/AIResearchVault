## Paper:188




1. Title: LEVER: Learning to Verify Language-to-Code Generation with Execution (LEVER: 学习利用执行验证语言到代码的生成)

2. Authors: Nianwen Song, Xiaoyu Kou, Yishu Miao, Nan Duan, Xiaodong Liu, Ming Zhou

3. Affiliation: Microsoft Research Asia (微软亚洲研究院)

4. Keywords: Reinforcement learning, Natural language processing, Language-to-code generation, Execution verification

5. Urls: Paper: http://proceedings.mlr.press/v139/song21f/song21f.pdf, Github: https://github.com/niansong1996/lever.

6. Summary: 

- (1):本文主要研究在自然语言描述下，代码生成的正确性验证问题。现有的方法中，基于语言模型的生成方法优点在于独立性强，但是正确率较低，基于执行结果的筛选方法正确率较高，但是错误的程序会影响执行结果。为此，本文提出了一个新的方法：Learning to Verify Language-to-Code Generation with Execution(LEVER), 该方法结合了生成和执行的优点，利用执行结果验证程序的正确性。

- (2):本文认为，基于语言模型的方法没有考虑程序的执行结果，无法得到程序的正确性保证；而基于执行结果的方法虽然有较高的正确率，却容易受到错误程序的干扰。本文提出的方法，利用执行结果的正确性验证，将在正确率和生成的效率等方面都有所提高。

- (3):本文提出的方法主要分为三个步骤：1）使用生成模型从输入的自然语言描述和少量示例程序中生成一组程序；2）使用执行器执行这组程序得到它们的执行结果；3）使用学习到的验证模型对每个程序进行验证，判断程序的正确性，并对程序进行排序。

- (4):本文的方法在文本转SQL的任务上进行实验，使用三种不同的CodeLM对比实验结果表明，LEVER始终提高了生成代码的执行精度，对于所有四个基准测试数据集，LEVER和code-davinci-002相结合能够在不使用任务特定的模型体系结构或提示方法的情况下获得4.6%到10.9%的性能提高，并取得了新的最高性能。消融实验表明验证结果对验证具有重要的影响，同时LEVER在低资源和弱监督设置下也能取得显著的提升。
7. Methods:

本文提出了一种新的方法：Learning to Verify Language-to-Code Generation with Execution (LEVER)，用于在自然语言描述下验证生成的代码的正确性。主要分为以下步骤：

- (1)：使用基于语言模型的生成模型从输入的自然语言描述和少量示例程序中生成一组程序；
- (2)：使用执行器执行生成的程序得到它们的执行结果；
- (3)：使用一个二元分类模型对每个程序进行验证，判断程序的正确性，并对程序进行排序，得出正确的程序。具体地，将生成的程序作为输入，结合自然语言描述和执行结果一同输入到验证模型中，得出每个程序是否正确的结果。

该方法在四个不同的语言到代码数据集上进行试验，使用三种不同的CodeLMs进行比较。实验表明，该方法在正确率和生成效率等方面有所提高，可以对自然语言描述下生成的程序进行有效验证。





8. Conclusion:

- (1): 本文提出了一种新的方法：Learning to Verify Language-to-Code Generation with Execution (LEVER)，解决了在自然语言描述下验证生成的代码的正确性问题。该方法吸取了基于语言模型的生成方法和基于执行结果的筛选方法的优点，兼顾了生成效率和正确性验证。

- (2): 创新点：本文提出了一种新的方法，将语言模型和执行结果进行结合，提高了程序生成的正确性验证。性能：实验结果表明，LEVER在正确率和生成效率等方面都有所提高，并在多个基准测试数据集中取得了最高性能。工作量：本文在代码生成和验证的实验方面进行了大量的工作，呈现了完整的实验结果和消融实验验证。同时，我们也提供了代码和数据集，方便其他研究人员进行相关工作研究。
