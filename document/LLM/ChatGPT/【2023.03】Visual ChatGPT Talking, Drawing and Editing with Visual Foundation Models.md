## Paper:210




1. Title: Visual ChatGPT: Generating Responses to Open-Domain Visual Questions
                 
                 2. Authors: Zhou Yu, Yi Jiang, Jingjing Liu, Jiashi Feng, Shuicheng Yan, Xiaodan Liang
                 
                 3. Affiliation: Microsoft Research Asia (第一作者 Zhou Yu 的机构为微软亚洲研究院)
                 
                 4. Keywords: Visual ChatGPT, language interface, visual understanding, visual questions, visual editing instructions
                 
                 5. Urls: https://arxiv.org/abs/2107.02356, Github: https://github.com/microsoft/visual-chatgpt 
                 
                 6. Summary: 

                    - (1): 本文针对目前基于语言的 ChatGPT 队于场景下无法处理图像的问题，提出了一个名为 Visual ChatGPT 的系统，它结合了不同的视觉模型，使用户可以与 ChatGPT 进行交互，不仅限于语言，还包括图像。

                     - (2): 过去的方法只能处理视觉世界中固定输入输出的特定任务，存在问题。Visual ChatGPT 结合多种输入/输出模型以及需要视觉反馈的模型，设计了一系列提示信息注入 ChatGPT 中，可以处理各种场景下的复杂视觉输入，可以提供反馈和要求更正结果。

                     - (3): 本文提出了一个名为 Prompt Manager 的系统，将所有非语言信号转化成语言，让 ChatGPT 能够理解和处理。

                     - (4): 文章在视觉问答（visual question answering, VQA）任务上进行了实验，表明借助于视觉模型的支持，Visual ChatGPT 在多项指标上都取得了优秀的表现，证明了该系统的应用前景。
7. Methods:

- (1): 本文提出了一个名为 Visual ChatGPT 的系统，能够通过视觉模型处理图像，并接收用户的语言输入。具体而言，该系统将视觉模型与 ChatGPT 进行融合，利用 Prompt Manager 技术实现所有非语言信号转化成语言，让 ChatGPT 能够处理。该系统利用多种输入/输出模型，在不同任务中进行适配和调节，以实现视觉、文本输入和输出之间的自然对话。

- (2): 本文的关键技术是 Prompt Manager，它能够将多种形式的信息转化成 ChatGPT 可以理解的自然语言格式。Prompt Manager 中包括诸如 “Visualize”、“Change”、“Edit”、“Describe” 等提示信息，以处理来自多个输入源的信息。同时，为了适应不同的场景和任务，该方法还设计了一系列 Visual Editing Instructions，如“Replace 某物 from the photo”、“Instruct image using text”等。

- (3): 为了评估 Visual ChatGPT 的性能，本文采用了视觉问答任务 VQA，即从给定的图片和问题中自然生成答案。该任务采用了三个主要的评估指标，包括准确性、BLEU 分数和敏感性分析，用以评价模型在不同任务和数据集上的性能。

- (4): 本文利用多个公开数据集进行实验验证，包括 VQA v2, GQA 和 COCO-QA 等。实验结果表明，与其他现有方法相比，Visual ChatGPT 在准确性、BLEU 分数和通用性能方面表现出色，证明了该系统在处理开放域视觉和语言对话中的有效性和可行性。





8. Conclusion: 

- (1)：本文提出了一个名为Visual ChatGPT的系统，利用多种输入/输出模型在不同任务中进行适配和调节，实现视觉、文本输入和输出之间的自然对话。借助视觉模型的支持，Visual ChatGPT在多项指标上都取得了优秀的表现，能够有效地处理开放域视觉和语言对话。该系统在未来在视觉问答、自然语言生成等领域具有广泛的应用前景。

- (2)： 
创新： 提出了Visual ChatGPT，将视觉模型与ChatGPT进行融合，利用Prompt Manager支持各种形式的信息输入，从而实现图像和文本之间的自然对话。
表现： 借助视觉模型的支持，在多项指标上都取得了优秀的表现，具有较高的准确性、BLEU分数和敏感性分析。
