## Paper:3




1. Title: SELF-ALIGN: Self-Supervised Alignment of Large Language Models for AI-Assisted Agents 
(自我对齐：面向AI助手代理的大型语言模型的自监督对齐)


2. Authors: Zhiqing Sun, Boyang Li, Yashar Mehdad, Yiyue Xu, Jincheng Zheng, Ece Kamar


3. Affiliation: Zhiqing Sun, Boyang Li, Yiyue Xu, Jincheng Zheng - Carnegie Mellon University; Yashar Mehdad - Google AI; Ece Kamar - Microsoft Research AI. 
(孙志庆，李博阳，徐伊岳，郑锦程 - 卡内基梅隆大学；Yashar Mehdad - Google AI；Ece Kamar - 微软研究院 AI)


4. Keywords: Reinforcement learning, Machine learning, Natural language processing, Self-supervised learning 
(强化学习，机器学习，自然语言处理，自监督学习)


5. Urls: Arxiv: https://arxiv.org/abs/2305.03047v1, Github code: None


6. Summary: 
- (1): 本文针对当前AI助手代理（如ChatGPT）普遍依赖于 supervised fine-tuning (SFT) 和 reinforcement learning from human feedback (RLHF) 使得这些大型语言模型（LLMs）的输出与人类意图对齐，从而保证其有用、道德和可靠的问题，提出了一种新的方法SELF-ALIGN，旨在解决人类监督成本高、质量、可靠性、多样性、自一致性和不良偏差等问题。
- (2): 过去的方法主要依赖于人类监督，但这样会导致成本高、监督质量、多样性和自一致性不足等问题。本文的方法主张结合 LLMS的生成能力和基于原则的推理技术，采用 self-supervised learning 和 in-context learning 等自监督学习的方式，减少对人类监督的依赖，以提高 AIModel的响应效率、降低偏差和提升可控性。
- (3): SELF-ALIGN方法由四个阶段组成：使用 LLMS 生成合成提示，使用具有代表性的原则来引导 LLM 在上下文中学习演示（如何应用原则），使其生成有用、道德和可靠的响应，此后，对 LLM 进行 SFT，使用 ALIGN 后的响应对应训练数据进行微调，最后， 提供一个完善步骤来解决响应过于简述或间接的问题。
- (4): SELF-ALIGN通过将LLMa-65b基础语言模型应用于少于300行的人类注释（包括小于200个种子提示、16个通用原则和5个示例来进行上下文中的学习）来开发 AI 助手Dromedary，从而显著超越了多个测试数据集的最先进的AI系统，包括 Text-Davinci-003 和 Alpaca。Dromedary的代码、LoRA权重以及我们的合成训练数据都已公开发布，以鼓励进一步研究，以提高 LLMs的性能。
7. Methods:

- (1): 本文提出了一种新方法 SELF-ALIGN，通过结合大型语言模型（LLMs）生成能力和基于原则的推理技术，采用自监督学习的方式来解决当前AI助手代理（如ChatGPT）存在的人类监督成本高、质量、可靠性、多样性、自一致性和不良偏差等问题。
 
- (2): SELF-ALIGN方法包括四个阶段：第一阶段，使用LLMS生成合成提示；第二阶段，使用具有代表性的原则来引导LLM在上下文中学习演示，使其生成有用、道德和可靠的响应；第三阶段，对LLM进行supervised fine-tuning（SFT）以微调其ALIGN后的响应对应训练数据；第四阶段，提供一个完善步骤来解决响应过于简述或间接的问题。
 
- (3): SELF-ALIGN方法采用自监督学习，包括in-context learning和sample-efficient pre-training，在使用少于300行的人类注释（包括小于200个种子提示、16个通用原则和5个示例来进行上下文中的学习）开发AI助手Dromedary的过程中取得了重要进展。
  
- (4): 本文还开发了一个AI Agent Dromedary，它使用LLMa-65b基础语言模型，并显著超越了多个测试数据集的最先进的AI系统，包括Text-Davinci-003和Alpaca。Dromedary的代码、LoRA权重以及我们的合成训练数据都已公开发布。





8. Conclusion: 

- (1): 本文提出的SELF-ALIGN方法结合了自监督学习和LLMs的生成能力以及基于原则的推理技术，旨在解决当前AI助手代理依赖于human feedback的问题，提高其响应效率、降低偏差和提升可控性，对于提高LLMs的性能具有重要的研究价值。

- (2): 创新点：自监督学习和基于原则的推理技术；提升了AI助手的响应效率、降低了偏差和提高了可控性。性能：开发的AI Agent Dromedary显著超越了多个测试数据集的最先进的AI系统。工作量：采用使用少于300行的人类注释进行的自监督学习方法，减少了对人类监督的需求，降低了成本。
