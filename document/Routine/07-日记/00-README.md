# 07-日记

> **用途**：每日学习记录、灵感、情绪、碎片想法
> **输入**：当天的学习、生活、观察
> **输出**：时间线、灵感库、情绪追踪

---

## 日记格式

```markdown
---
tags: [daily, YYYY-MM-DD]
date: YYYY-MM-DD
mood: 😊/😐/😔/🤩
energy: 1-10
focus: 1-10
---

# YYYY-MM-DD 周X

## 今日学习

## 今日灵感

## 今日情绪

## 明日计划

## 碎片笔记
```

## 日记 Pipeline

1. **晨间**（5 min）：写今日计划，选 1-2 个 AI-Tasks 主题
2. **晚间**（5 min）：写今日完成、灵感、情绪
3. **周末**（10 min）：回顾本周日记，提取关键洞察到 [[06-研究复盘日志]]

---

## 灵感收集规则

- 任何时刻有灵感，立即记录到「今日灵感」
- 每周日整理灵感，有价值的转到对应主题
- 模糊的灵感不要删除，标记为「待验证」
