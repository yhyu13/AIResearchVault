6. Summary:
- (1): This paper focuses on implementing a robotic system capable of performing General Purpose Service Robot (GPSR) tasks in a daily life environment.
7. Methods:

- (1): The authors propose a foundation model for open vocabulary task planning and execution in a robotic system capable of performing General Purpose Service Robot (GPSR) tasks in a daily life environment.

- (2): The foundation model utilizes a hierarchical structure consisting of high-level task and low-level motion planning modules.

- (3): The high-level task planning module generates a sequence of abstract actions given a high-level task description and a set of available objects and locations.

- (4): The low-level motion planning module converts the abstract actions into low-level robot actions using a state machine formalism.

- (5): The foundation model supports open vocabulary input, allowing the robot to understand and generate instructions with previously unseen words.

- (6): The authors evaluate the performance of the proposed system in experiments conducted on a real robot, demonstrating its capability to successfully execute GPSR tasks with open vocabulary input in a daily life environment.





8. Conclusion:

- (1): The significance of this work lies in the proposal of a foundation model for open vocabulary task planning and execution in a robotic system capable of performing General Purpose Service Robot (GPSR) tasks in a daily life environment.
