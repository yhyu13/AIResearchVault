## Paper:5




1. Title: Do We Know What We Don’t Know? 

2. Authors: Elior Sulem, Jamaal Hay, Dan Roth

3. Affiliation: None (it is not mentioned in the abstract)

4. Keywords: Natural Language Understanding, Extractive QA, IDK phenomenon, SQuAD 2.0, Recognizing Textual Entailments (RTE)

5. Urls: Paper - None (only available on ACL anthology), Github - None

6. Summary:

- (1): 本文探讨了自然语言理解中一个重要的问题，即如何确定文本片段是否提供了所需的信息。

- (2): 过去的方法主要集中在基于抽取式问答标准数据集SQuAD 2.0中添加无法回答的问题，但仅仅在该数据集上训练的最好系统，在域外场景下会面临严重降低的性能。作者认为这些方法并不能解决IDK现象（无法回答问题）的根本问题，因此提出了一种针对机器阅读理解中IDK现象的指标体系，并提出了一种基于这些指标的模型训练策略。

- (3): 作者首先构建了一个域外语料库，专注于简单的基于事件的问题，并区分了两种IDK问题类型：竞争问题（上下文中包含与期望答案相同类型的实体）和非竞争问题（上下文中没有与期望答案相同类型的实体）。作者设计了一种衡量模型IDK现象表现的指标，并提出使用关联任务Recognizing Textual Entailments (RTE)来提升模型性能。

- (4): 作者的模型在SQuAD 2.0数据集和ACE-whQA数据集上实现了相对较好的性能，特别是在经过MNLI附加预训练后的模型在IDK问题上表现显著提高。作者的研究为解决机器阅读理解中IDK现象提供了一种新的思路和解决方法。
7. Methods: 

- (1): 本文的方法ological idea是通过构建一个专注于简单基于事件的问题的域外语料库，在其中区分了两种IDK问题类型，即竞争问题和非竞争问题。在此基础上，作者提出了一种以IDK现象为目标的指标体系。

- (2): 作者提出了一种基于以IDK现象为目标的指标体系的模型训练策略，其中结合了关联任务Recognizing Textual Entailments（RTE），并设计了一种衡量模型IDK现象表现的指标。

- (3): 作者的模型在SQuAD 2.0数据集和ACE-whQA数据集上实现了相对较好的性能。特别是，在经过MNLI附加预训练后的模型在IDK问题上表现得更为显著。

- (4): 本文的创新点在于提出了一种以IDK现象为目标的指标体系，有助于从源头上解决IDK现象问题。同时，作者的研究还提出了基于该指标体系的模型训练策略，以及一种结合关联任务来提升模型性能的方法，为解决机器阅读理解中IDK现象提供了一种新的思路和解决方法。





8. Conclusion: 

- (1): 本文的意义在于探讨了自然语言理解中一个重要的问题，并提出了一种新的思路和解决方法，即以IDK现象为目标的指标体系和基于该指标体系的模型训练策略，有助于从源头上解决机器阅读理解中IDK现象问题。同时，通过探索关联任务来提升模型性能，为构建抽取式问答系统提供了一种新的思路。

- (2): 创新点：提出了以IDK现象为目标的指标体系，从源头上解决机器阅读理解中IDK现象问题；表现：作者的模型在SQuAD 2.0数据集和ACE-whQA数据集上实现了相对较好的性能；工作量：本文涉及域外语料库构建、模型设计等多个方面，属于较为繁琐的工作。
