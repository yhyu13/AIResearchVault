## P1 — 持续关注（Trial）

> 有潜力、值得实验的技术。目标：了解原理、跑通 Demo。

| 技术 | 主题 | 为什么 | 实验计划 |
|------|------|--------|----------|
| **ReSTIR LoD** (SIGGRAPH 2026) | 几何 LoD 切换下的时空复用 | 通过 UV-based surface point mapping 解决 LoD 切换导致的 temporal reuse 断裂。含 Jacobian 一致性证明。 | 阅读 Section 4.4 的映射构造；复现 Figure 5 的 Jacobian 分析；将 change-of-variables 细节补充到笔记 |
| **CGNS** (HPG 2026 Best Paper) | 兼容性引导的邻居选择 | 用位置+法线兼容性启发式替代 uniform disk sampling，WRS 选 M 个最兼容邻居。GitHub 已开源（Falcor 8.0）。 | 克隆 [ReSTIR-CGNS](https://github.com/orion-junkins/ReSTIR-CGNS) 仓库，阅读 CGNSUtils.slang 和 WRSReservoir.slang |
| **Stochastic Pairwise MIS** (EG 2026) | 无偏大核空间复用 | 将像素按 GBuffer 分类为 cell，随机选 cell 后评估 N_bar=3 高贡献候选。Appendix A 含完整无偏性证明（tower property）。 | 复现 Appendix A 的无偏性证明，与 GRIS 原始推导对比；评估对现有 spatial reuse 的扩展 |
| **Multi-Layer Reservoir Splatting** (SIGGRAPH 2026) | 遮挡区域时间复用 | 将 Reservoir Splatting (SIGGRAPH 2025) 扩展为多层，解决 disocclusion 后 temporal reuse 失效。需重新证明 MIS 无偏性。 | 跟踪 supplemental 中的无偏性推导；评估与现有 temporal reuse 模块的集成可行性 |
| **ReSTIR PG** (SIGGRAPH Asia 2025) | 从 ReSTIR 路径提取引导分布 | 用 resampled paths 的 density estimation 拟合 4-component vMF 模型，one-sample MIS 与 BSDF sampling 结合。闭环 ReSTIR 与 path guiding。 | 复现核心算法；推导 vMF 拟合与 MIS 权重的数学细节；评估 MAPE 降低效果 |
| **RoyalTracer-DX** | 开源 DX12 ReSTIR PT | 统一 DI/GI reservoir、pairwise MIS、temporal permutation sampling、duplication map M_cap 调制。 | 阅读源码作为个人 ReSTIR 理解的代码对照；特别关注 unified reservoir 的 MIS 权重处理 |
| **Bevy Solari 0.19** | Rust 开源 ReSTIR GI | 改进空间采样（5次尝试+半径减半）、光滑金属跳过 GI、修正 BRDF lobe 与 Fresnel。完全开源。 | 阅读源码，理解 ReSTIR GI 在真实引擎中的工程权衡；注意其简化相对于 NVIDIA 版本 |
| **NIRC** (Eurographics 2025) | 神经入射辐射缓存 | tiny NN 学习 L_i，Two-Level MC 实现无偏。比 NRC 快 5-10×。可与 ReSTIR 互补（ReSTIR 负责直接光，NIRC 负责间接光）。 | 跑通开源实现，评估与 ReSTIR 集成的方差削减效果 |

## P2 — 了解即可（Assess）

> 新兴技术、保持关注。目标：知道是什么、能解决什么问题。

| 技术 | 主题 | 为什么 | 关注渠道 |
|------|------|--------|----------|
| **ReSTIR BDPT** (ACM TOG 2025) | 双向 ReSTIR 路径追踪 | 将 GRIS 扩展到 BDPT，支持 caustics。但 ~50ms/帧、8GB 内存，距离实时有差距。 | 跟踪 SIGGRAPH 2026 展示后的讨论；理解 technique-specific MIS 与多 technique 场景下的 Jacobian 扩展 |
| **Gradient-Domain ReSTIR** (EG 2026) | 梯度域实时路径追踪 | 将 paired-pixel 样本作为 ReSTIR 复用单元，需额外 Jacobian 项（path difference 的 change-of-variables）。生产价值有限。 | 阅读论文中的梯度域 shift mapping；关注其对路径空间扩展的数学处理 |
| **Spatio-Temporal Control Variates** (SIGGRAPH 2026) | 控制变量法降方差 | 在 ReSTIR 时空采样中引入 control variates，需仔细调和无偏性约束。目前仅会议标题，细节待确认。 | 关注 SIGGRAPH 2026 (2026-07-19~23) 召开后的论文全文与 supplemental |
| **Generalizable Light Transport 3D Embedding** (SIGGRAPH 2026) | 可泛化 GI 神经预测 | 点云 + 线性 Transformer 编码长程光传输，百万级三角面实时预测。只能处理 diffuse GI。 | 阅读 arXiv:2510.18189；理解"学习替代采样"的互补视角 |
| **Real-Time GI for Dynamic 3D Gaussian Scenes** | 动态 3DGS 实时 GI | 推导 surface-based LTE 用于 3D Gaussians，compound stochastic ray tracing + two-level radiance cache。 | 关注代码是否开源；借鉴其 radiance cache 设计 |
| **GI-GS** | 3DGS 全局光照分解 | 直接/间接光分解，HDR 环境图驱动。实时但忽略 specular GI（恰好是 ReSTIR 专长可切入的方向）。 | 跟踪后续版本是否补全 specular GI |
| **DLSS 4.5 / Multi-Frame Generation** | 第二代 Transformer 帧生成 | RTX 50 独占，性能模式画质接近原生。属于后处理而非 GI 算法本身。 | 跟踪 NVIDIA 技术博客；评估对 ReSTIR 输出后处理的价值 |
| **Neural Shaders / RTX Neural Rendering** | Shader 内嵌神经网络 | NRC 可缓存间接光照，减少 ReSTIR 路径长度。但生态封闭，跨厂商支持为零。 | 在 Falcor / NVIDIA SDK 中试用；跟踪标准化进程 |
| **AI 3D Video Generation** | 实时可控 3D 视频生成 | Google Veo 3/3.1、Runway Gen-3 Alpha、Captain Safari (pose-aligned 3D world memory) 等已实现 text/image-to-video 的 3D 一致性生成。2026 年向 real-time 和可交互方向演进。对游戏而言，意味着未来可能用生成式模型替代传统渲染管线的一部分。 | 跟踪 Veo 3.1、Runway Gen-3 的 API 更新；关注 world engine（如 Captain Safari）的 camera-controlled 生成质量 |
| **AI-Native Game / World Models** | 以 AI 世界模型为核心运行的游戏 | Oasis (500M 参数实时生成 Minecraft-like 世界)、Genie 3 (DeepMind, 720p@24fps 可交互生成世界)、DIAMOND (diffusion world model 训练 agent)、NVIDIA Cosmos (物理感知的 world foundation model)。2026 年被认为是 AI-native game 元年。可能从根本上改变游戏内容生成方式。 | 跟踪 Genie 3 / Oasis 的开源进展；评估 world model 与现有游戏引擎的 hybrid 集成路径；关注 on-device inference (RTX 50 / PS6 dev kit) 的延迟表现 |

## P3 — 暂时观望（Hold）

> 不成熟或已过时的技术。目标：了解为什么被替代。

| 技术 | 主题 | 为什么 | 替代方案 |
|------|------|--------|----------|
| **纯 Light Tree / Lightcuts** | 层次化光源聚类采样 | ReSTIR O(1) 成本已全面超越 Light Tree O(log N)；动态光源更新开销在实时场景中不可接受。 | 全面迁移至 ReSTIR DI / ReSTIR GI |
| **纯 Screen-Space GI (SSAO/SSR/SSGI)** | 屏幕空间近似全局光照 | 缺少屏幕外信息、物理不正确。UE5 Lumen HWRT 已覆盖其应用场景。 | 使用 Lumen HWRT / ReSTIR GI / DDGI |
| **纯 NeRF / Instant-NGP** | 神经辐射场实时渲染 | 3D Gaussian Splatting 在速度（100-200×）、训练时间、VRAM 上全面超越。 | 使用 3D Gaussian Splatting 或 mesh-based 方案 |
| **纯扩散模型替代路径追踪** | 生成式 AI 渲染 | ~1K SDR 输出，不保证物理正确性和多视角一致性。生产管线仍用传统 PT。 | 采用 hybrid AI + 物理渲染方案 |
| **UE 5.6 SWRT** | Lumen 软件光追路径 | Epic 已明确 deprecated，未来只聚焦 HWRT。减少维护负担。 | 迁移至 Lumen HWRT |
| **OpenGL / WebGL 2.0** | 传统图形 API | 无硬件 RT、无 compute shader、无现代扩展。Khronos 仅维护不向 OpenGL 加新功能。 | 使用 Vulkan / D3D12 / WebGPU |
