## Paper:5




1. Title: Describe, Explain, Plan and Select: Interactive Planning with Large Language Models Enables Open-World Multi-Task Agents

                 
2. Authors: Zihao Wang, Shaofei Cai, Anji Liu, Xiaojian Ma, Yitao Liang

                 
3. Affiliation: 北京大学人工智能研究院, 北京, 中国

                 
4. Keywords: Reinforcement learning, Planning, Large language models, Interactive approaches, Multi-task agents, Minecraft

                 
5. Urls: https://arxiv.org/abs/2302.01560

Github: https://github.com/CraftJarvis/MC-Planner (code available)

                 
6. Summary: 


- (1): 本文研究了计划问题在Minecraft游戏中的应用，该游戏是一个多任务、实体智能体开放式环境下的挑战。其中面临两个主要问题：长期任务涉及精确的多步推理，vanilla planners无法考虑复杂计划中当前agent的距离，也无法对并行子目标进行排序。本文提出了“Describe, Explain, Plan and Select” (DEPS)的交互式计划方法基于Large Language Models（LLMs）。


- (2): 本文基于现有的交互式方法进行了改进，使用LLM进行前后错误校正、使用可学习模块Goal Selector对子目标排序，使得得到的计划更加高效。同时，本文提出的交互式计划方法基于LLMs已经被成功应用于该游戏，并在70多个Minecraft任务上得到了良好的性能表现，同时也大大提升了综合效能。这使得该方法有望成为未来多任务情境下的重要工具。


- (3):本文提出了基于交互式方法和LLMs的新型计划模型。其中LLMs可以对自然语言生成更准确的预测，也可以对计划进行评估。本文提升了LLM的表达能力，嵌入Vocabulary of Minecraft，帮助计划获得更鲁棒的效能。

 
- (4):本文在Minecraft的"ObtainDiamond"grand challenge任务中成功地获得了一系列优秀的性能，这表明了提出的交互式计划方法在构建多任务代理方面具有非常大的潜力。同时，我们在丰富的实验中也验证了我们的方法的优越性，这使得我们的交互式计划方法能够有效地克服了以往使用Minecraft进行多任务代理建设所面临的挑战和问题。
7. Methods: 

- (1): 本文提出了基于Large Language Models（LLMs）的交互式计划模型，称作“Describe, Explain, Plan and Select”（DEPS）。该方法主要分为四个步骤：a）按需求“描述”任务，b）通过提问回答等方式“You explain”更多信息，c）可交互式“Plan”策划，d）用Goal Selector对子目标排序，进而作出最终的计划决策。

- (2): 本文还对交互式方法进行了改进，使用可学习模块Goal Selector对子目标排序，使得得到的计划更加高效。同时，本文提出的交互式计划方法基于LLMs已经被成功应用于Minecraft游戏，并在70多个多任务代理任务上得到了良好的性能表现，同时也大大提升了综合效能。 

- (3): 在实现中，本文使用了限制交互次数的模式，使得计划决策时不会耗费过多时间。同时，本文使用了任务预处理，将任务表述嵌入到LLMs的词汇中，提升了LLM的表达能力，进而提升了计划的效能检验。

- (4): 本文进行了大量的实验验证，包括 ablation_study（探究DEPS的最大迭代次数与可执行目标数对性能表现的影响）、task_success_rates（对70个Minecraft多任务代理任务的性能评价）、obtain_diamond_challenge（对挖掘钻石任务的评估）。实验结果表明，DEPS方法在构建多任务代理方面具有良好的性能和效率，并在Minecraft游戏中取得了优秀的表现。





8. Conclusion: 

- (1): 本文提出了一种基于交互式方法和LLMs的新型计划模型，用于解决多任务代理在开放式情景下的挑战。通过该方法，本文在Minecraft游戏中取得了优秀的表现，跨越了70多个多任务代理任务，同时也成为了能够挖掘钻石的第一个基于计划的代理。该方法在未来多任务情境下的便利性和有效性具有很大的潜力。

- (2): 创新点：本文创新地使用了基于LLMs的交互式计划模型，用于多任务代理中的开放式情境。这在这一领域中是具有应用价值的。性能：本文在Minecraft游戏中取得了很好的表现，跨越了多个任务，同时也成为了第一个基于计划的代理，可以挖掘到钻石。工作负载：在实验中，本文使用了限制交互次数的模式，以及任务预处理，使得计划决策时不会耗费过多的时间，并且任务表述嵌入到LLMs的词汇中，有助于提升LLM的表达能力。
