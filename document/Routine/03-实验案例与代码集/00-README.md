## 实验 Pipeline

1. **设计**（周末）：AI 辅助设计实验方案
2. **实现**（周末）：编写代码，AI 辅助调试
3. **运行**（周末）：收集结果
4. **分析**（周日）：AI 辅助分析，你得出结论
5. **分享**（周日）：整理成博客或 Notebook
