1. Title: Text and Code Embeddings by Contrastive Pre-Training

2. Authors: Arvind Neelakantan, Tao Xu, Raul Puri, Alec Radford, Jesse Michael Han, Jerry Tworek, Qiming Yuan, Nikolas Tezak, Jong Wook Kim, Chris Hallacy, Johannes Heidecke, Pranav Shyam, Boris Power, Tyna Eloundou Nekoul, Girish Sastry, Gretchen Krueger, David Schnurr, Felipe Petroski Such, Kenny Hsu, Madeleine Thompson, Tabarak Khan, Toki Sherbakov, Joanne Jang, Peter Welinder, Lilian Weng

3. Affiliation: OpenAI（OpenAI）

4. Keywords: reinforcement learning, machine learning, contrastive learning, self-supervised learning, pre-training, natural language processing, text embeddings, code embeddings

5. Urls: Paper: arXiv:2201.10005v1 [cs.CL] 24 Jan 2022, Github: None

6. Summary:

- (1):本文研究文本和代码嵌入的对比预训练。嵌入模型是将数据映射为低维向量表示并具有丰富的语义信息。在此之前的相关研究大多是定制模型来解决不同的用例，这些模型在数据集选择、训练目标和模型架构等方面各不相同。因此，本文提议使用自监督的对比预训练方法来训练模型并获得高质量的嵌入向量，用于文本语义搜索和计算文本相似度等应用领域。
- (2):以往的方法往往通过定制模型来获取高质量的文本和代码嵌入向量。但这些模型并不是所有应用场景都通用的，需要选择不同的数据集和训练方法，因此十分耗时和耗力。同时，这些定制的方法也容易受限于数据规模、嵌入维度等因素影响，限制了其推广应用的能力。因此，本文提出使用自监督的对比预训练方法来训练模型，减少了对大量标注数据的依赖，提高了模型的推广性和泛化性 ability。
- (3):本文采用自监督的对比学习方法，通过最大化正确样本和负样本之间的相似性，来训练文本和代码嵌入向量。而这里的负样本是由原始数据中的随机噪声生成的，可以有效地增强模型的泛化能力和对噪声的鲁棒性。除此之外，本文还使用了基于Transformer的模型来实现对比学习和文本嵌入功能。
- (4):在多个基准测试中，本文的模型取得了高度优异的结果：在线性探测分类的7项任务中，无监督学习模型相对于前期最先进的无监督学习和有监督学习模型的综合得分分别提高了4％和1.8％。在大规模的文本语义搜索中，我们的模型在MSMARCO、自然问题和TriviaQA等基准测试中相对于之前最好的无监督方法的综合得分提高了23.4％、14.7％和10.6％，验证了其在文本和代码嵌入方面的高质量和实际推广应用价值。
7. Methods:

- (1): 本文采用自监督的对比预训练方法，通过最大化正确样本和负样本之间的相似性，来训练文本和代码嵌入向量。
- (2): 训练集包含形如{(xi, yi)}N i=1的成对样本，其中(xi, yi)对应于正样本对，表示xi和yi在语义上相似或上下文中相关。
- (3): 使用基于Transformer的模型来实现对比学习和文本语义搜索功能。具体地，给定训练对(x, y)，使用Transformer编码器E来分别处理x和y以及[EOS]特殊标识符生成它们的嵌入向量。
- (4): 在训练过程中，采用噪声生成器从原始数据中生成负样本，并通过最小化距离来训练模型，同时减少了对大量标注数据的依赖性。
- (5): 在多个基准测试中，证实了本文模型在文本和代码嵌入方面的高质量和实际推广应用价值。





8. Conclusion: 

- (1): 本研究意义重大，探索了通过自监督对比预训练方法来训练文本和代码嵌入向量的有效性，提高了对大量标注数据的依赖。本文提出的方法可以更好地推广应用，比现有方法更具通用性，可以在文本搜索、代码搜索等方面取得更好的效果，具有广阔的实际应用前景。

- (2): 创新点是本文采用自监督的对比预训练方法训练模型，减少了对大量标注数据的依赖性；性能方面，在多个基准测试中，本文模型表现优异，取得了新的最佳结果；工作量方面，本文方法极大地减少了对定制模型的需求，但是在句子相似度任务上性能较差，并出现了意外的训练行为。
