## Paper:2




1. Title: Robot Behavior-Tree-Based Task Generation with Large Language Models

2. Authors: Yue Cao and C.S. George Lee

3. Affiliation: 美国普渡大学埃尔莫尔电气和计算机工程学院

4. Keywords: Robot task, Large language model, GPT-3, Behavior tree, Task planning

5. Urls: arXiv:2302.12927v1 (paper), Github: None

6. Summary: 

- (1): 本文研究背景为机器人任务生成。
- (2): 过去的方法主要集中在固定的基本任务上，难以推广到新的任务领域。本文提出了一种全新的机器人任务生成方法，可自动横跨领域地生成行为树任务。它使用最先进的大型语言模型，消除了需要预定义的原始任务集，而只需要描述所需的抽象任务。
- (3): 本文提出了一种基于状态转移的 Prompt 设计方法，将其与行为树嵌入式搜索相结合，运用现代大型语言模型进行机器人任务生成。利用GPT-3自动且跨域地生成行为树任务。 
- (4): 该方法在机器人任务生成方面取得了很好的效果，无需手动设计行为树，只需要提供抽象任务，就能快速生成行为树任务。在实验中，该方法在复杂任务中表现出了良好的性能。
7. Methods: 

- (1): 本文采用基于状态转移的Prompt设计方法，结合行为树嵌入式搜索，借助现代大型语言模型(GPT-3)，实现机器人任务生成。

- (2): 本文提出了Phase-Step Prompt方法，该方法能够自动生成3层行为树。针对生成的行为树，本文提出了两种扩展方法：根据机器人能力进行分解和直接修改Prompt。同时，本文引入了Fallback节点和条件节点以处理生成树中的额外说明。

- (3): 本文开发了自动选择源任务的方法，该方法通过与现有知识库中的行为树进行语义相似度匹配，自动选择源任务。值得一提的是，本文使用了OpenAI公司的GPT-3和ChatGPT模型，并进行了实验验证。





8. Conclusion:

- (1): 本文提出了一种全新的机器人任务生成方法，使用最先进的大型语言模型，可以消除需要预定义的基本任务集。该方法不仅可以自动、跨域地生成行为树任务，而且可以避免手动设计过程，即只需要提供抽象任务，就能快速生成行为树任务。该方法在机器人任务生成方面具有重要的意义和应用前景。

- (2): 创新点：本文提出的机器人任务生成方法采用最先进的大型语言模型，消除了需要预定义的基本任务集，避免了手动设计过程，并可以自动跨域生成行为树任务。该方法具有很好的创新点。性能：实验结果表明，本文提出的机器人任务生成方法在复杂任务中表现出了良好的性能，具备很好的应用前景。工作量：本文提出的机器人任务生成方法需要建立基于状态转移的Prompt，并进行行为树嵌入式搜索，然后与现成的知识库中的行为树进行语义相似度匹配，需要一定的工作量。
