## Paper:8




1. Title: AIPerf: 自动机器学习作为 AI-HPC 基准测试

2. Authors: Zhixiang Ren, Yongheng Liu, Tianhui Shi, Lei Xie, Yue Zhou, Jidong Zhai, Youhui Zhang, Yunquan Zhang, Wenguang Chen

3. Affiliation: Peng Cheng Laboratory（彭城实验室）

4. Keywords: high performance computing, artificial intelligence, benchmark, automated machine learning

5. Urls: 
- Paper: https://arxiv.org/abs/2008.07141 
- Github: None

6. Summary: 
- (1): 本文研究的背景是深度学习、机器学习、人工智能需要对于海量数据进行训练、预测和推理等大计算量的运算。为了满足运算的需要，出现了各种高性能计算设备；然而这些设备的异构性限制了软件应用程序的灵活性和性能表现。同时，为评估人工智能与高性能计算混合应用的性能特征，需要开发合适的基准测试程序。
- (2): 过去的方法主要是使用传统的高性能计算（HPC）基准测试程序来评估人工智能程序的性能；但是，传统的基准测试不能很好地模拟人工智能程序的计算与 I/O 行为特性，也不能自适应地针对不同的硬件环境进行测试。目前使用的 AI 基准测试程序，如 MLPerf，由于问题规模固定，缺乏可扩展性。本文提出一种使用自动机器学习（AutoML）的端到端基准测试程序，旨在模拟真实应用场景并自适应地适应不同规模的硬件环境。同时，本文的方法在处理算法的并行性和灵活性方面做了充分考虑，以实现各种不同的系统配置。为了衡量人工智能程序的性能，使用每秒操作数（OPS）作为主要指标来衡量人工智能程序的性能。这种基准测试程序在各种不同硬件环境下的验证结果表明了该程序的可靠性和可扩展性。
- (3): 本文的研究方法主要是使用了自动机器学习优化算法，并通过各种灵活的算法实现，以适应不同的系统硬件和软件环境。另外，将每秒操作数（OPS）作为衡量人工智能程序性能的指标。
- (4): 本文的方法在多个系统上进行了验证，从 4 个节点的 32 个 NVIDIA Tesla T4 测量到 512 个节点的 4096 个 Huawei Ascend 910，结果表明了该程序的弱可扩展性和良好的测试结果。通过这种基准测试程序，可以轻松地扩展和排名人工智能与高性能计算的应用。
7. Methods: 

- (1): 本文提出了一种基于自动机器学习（AutoML）的端到端基准测试程序，旨在模拟真实应用场景并自适应地适应不同规模的硬件环境。通过使用自动机器学习优化算法和灵活的算法实现，以适应不同的系统硬件和软件环境。使用每秒操作数（OPS）作为主要指标来衡量人工智能程序的性能。 

- (2): 本文的研究方法主要包括三点：神经网络结构搜索、超参数优化和工作流。在神经网络结构搜索方面，本文采用了自动机器学习算法，并使用残差网络（ResNet-50）作为初始模型。超参数优化方面，本文采用了贝叶斯优化算法对批量大小和核大小进行优化。在工作流方面，本文将NNI框架进行了修改，以实现复制节点异步执行模型生成和训练，并利用数据并行性和同步allreduce策略对各种可用AI加速器进行并行训练。 

- (3): 本文的基准测试程序在多达512个节点的4096个Huawei Ascend 910等不同的硬件环境下进行了验证，结果表明其可靠性和可扩展性。本文使用每秒操作数（OPS）作为衡量人工智能程序性能的指标。计算OPS的方法是将操作数看做数学问题，并计算完成训练和验证所需的操作总数。 

- (4): 本文的研究具有一定的创新性和实用性，可以对人工智能与高性能计算混合应用的性能特征进行评估和排名，为人工智能硬件的选型和系统的设计提供参考。





8. Conclusion: 

- (1): 本文提出了一种使用自动机器学习（AutoML）的端到端基准测试程序，旨在评估和排名人工智能与高性能计算混合应用的性能特征；同时，提出了独立于深度学习框架和其他软件实现的计算操作率计算方法，将其作为主要指标（每秒操作数，OPS）评估人工智能程序的性能。该基准测试程序在各种不同的硬件环境下进行了验证，证明其可靠性和可扩展性。
  
- (2): 创新点方面，本文提出使用自动机器学习（AutoML）的端到端基准测试程序并使用独立于深度学习框架和其他软件实现的计算操作率计算方法作为主要指标，从而提高了基准测试程序的可靠性和扩展性。性能方面，由于使用了自动机器学习优化算法，所以能够适应不同的系统硬件和软件环境，从而增强了性能表现。工作负载方面，本文选择了高度可扩展和代表性的自动机器学习应用（ResNet-50），使得基准测试程序能够模拟真实应用场景。其中，本文的方法在处理算法的并行性和灵活性方面做了充分考虑，以实现各种不同的系统配置。
