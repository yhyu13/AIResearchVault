## Paper:235




1. Title: A Systematic Evaluation of Large Language Models of Code
       
       2. Authors: Frank F. Xu, Uri Alon, Graham Neubig, Vincent J. Hellendoorn
       
       3. Affiliation: 卡内基梅隆大学计算机科学院(School of Computer Science, Carnegie Mellon University)
       
       4. Keywords: large language models, natural language processing, programming language, PolyCoder, Codex
       
       5. URLs: 
                Paper: https://arxiv.org/abs/2202.13169v3
                Code: https://github.com/VHellendoorn/Code-LMs
       
       6. Summary: 
       
             - (1): 本文研究的背景是：大语言模型已经在自然语言处理方面已经得到了很好的应用，在源代码处理领域上也在近年来得到越来越多的关注。
             
             - (2): 过去的方法主要包括人工编写模型、LSTM模型等。这些方法在语言模型具有固定长度、耗费人工时间、需要大量的人工输入等方面有很明显的缺点。本文试图 fill in some blanks，通过对已有最大的模型进行系统评估，从而找到最佳的模型。本文所采用的方法需要的硬件资源更为充足，采样更加均匀，模型也更加充分考虑到了相关的上下文信息。
             
             - (3): 本文提出了一种系统性评估方法，包括了语言模型的设计方案、训练数据、语言代码等方面，从而可以找到最佳的模型。本文另外还介绍了一种多语言代码的开源模型——PolyCoder，包括249GB的代码，基于GPT-2架构，参数大小为2.7B，完成与其他模型的性能比较。
             
             - (4): PolyCoder在不同的编程语言中，性能都表现良好，在C语言环境中甚至比Codex性能更佳。 然而，其他主要的语言模型则存在一些缺陷，如代码生成和自然语言描述合成代码方面表现一般。 本文的研究为该领域的未来研究和应用提供了更好的支持。
7. Methods: 

- (1): 本文主要利用统一的评估方法对大规模语言代码模型展开了评估研究，包括典型的预训练方法、训练数据以及语言代码等方面，以期找到最佳的模型。
 
- (2): 文章采用了一种较为充分考虑上下文信息的评估方法：PolyCoder模型，它基于GPT-2架构，包含249GB的代码，是一个开源多语言代码模型。与其他模型相比，它具有更好的性能表现，在C语言环境中甚至比Codex的性能更佳。
 
- (3): 为了更全面地评估各大语言代码模型的表现，本文采用了内部评估和外部评估两种方法。内部评估采用了对于不同语言的代码数据集，计算其困惑度；而外部评估则针对生成代码任务，随机抽取来自不同编程语言的164个prompt，并通过温度参数不同的soft-max策略进行模型拟合，最终通过检查生成的代码是否正确，并计算其rank指标进行模型表现的评估比较。除此之外，本文还比较了基于Encoder-Decoder和Masked Language Models方法的另外几个语言代码模型的表现差异。





8. Conclusion: 

- (1): 本文开展对大型语言模型在代码处理领域的系统性评估，比较了多种大型语言模型的性能差异并发现了一种可开源使用的多语言代码模型：PolyCoder。该研究为今后该领域的研究提供了更好的支持，并在应用上具有相当的潜力。

- (2): 创新点：本文采用了普遍但较少被使用的多任务学习方式，增强了语言模型对上下文的解释力，同时也提高了代码生成的准确性。性能方面，PolyCoder在不同编程语言中表现良好，尤其是在C语言中表现更佳，表明其适用性较广。工作量方面，本文所提出的多语言代码模型需要极为丰富的训练数据和强大的硬件资源支持，对于一般研究者来说构建和优化模型比较困难，还需要进一步下功夫。
