According to [1](https://learnprompting.org/docs/prompt_hacking/defensive_measures), prompt hack techniques are methods of manipulating the input or output of a machine learning model to achieve a desired result, such as extracting information, altering behavior, or causing errors. Some examples of prompt hack techniques are:

-   Prefixing: adding a prefix to the input that changes the model's interpretation or expectation of the input.
-   Suffixing: adding a suffix to the input that changes the model's output or confidence.
-   Infixing: inserting text within the input that changes the model's attention or context.
-   Outfixing: adding text outside the input that changes the model's output format or domain.

Some principles behind prompt hack techniques are:

-   Exploiting the model's biases or weaknesses, such as memorization, overfitting, or lack of robustness.
-   Leveraging the model's capabilities or strengths, such as generalization, inference, or generation.
-   Understanding the model's architecture or parameters, such as attention mechanisms, embeddings, or layers.

Some prevention measures for prompt hack techniques are:

-   Fine-tuning the model on a specific task or domain, so that it does not need a prompt or is less sensitive to prompt variations [1](https://learnprompting.org/docs/prompt_hacking/defensive_measures).
-   Using soft prompting, which is a method of providing hints or guidance to the model without explicitly specifying the output format or domain [1](https://learnprompting.org/docs/prompt_hacking/defensive_measures).
-   Using white/blacklists for inputs and outputs, output validation, and input/output length restrictions [1](https://learnprompting.org/docs/prompt_hacking/defensive_measures).
-   Using app-based authentication methods instead of SMS-based or phone call methods to protect against number port out schemes [2](https://cybersecurity.att.com/blogs/security-essentials/hacker-prevention).
