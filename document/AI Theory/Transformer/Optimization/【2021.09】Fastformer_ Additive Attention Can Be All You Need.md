## Paper:2




1. Title: Fastformer: Additive Attention Can Be All You Need (Fastformer: 加性注意力可以解决所有问题)

2. Authors: Chuhan Wu, Fangzhao Wu, Tao Qi, Yongfeng Huang, Xing Xie

3. Affiliation: 作者一的单位为清华大学电子工程系及BIST，Beijing 100084

4. Keywords: Fastformer, Transformer, attention, context modeling, long input sequence

5. Urls: Paper link: https://arxiv.org/abs/2108.09084v6, Code link: https://github.com/wuch15/Fastformer

6. Summary:

- (1): 本文旨在提升Transformer模型的效率，因此，作者提出了Fastformer方法:一种基于加性注意力机制的高效Transformer模型。该模型通过对全局上下文进行加性注意力机制建模，代替了传统Transformer中仅对token间的交互建模的方法；通过使用元素相乘的方式，进一步学习获得全局上下文感知的key matrix，最后将其与attention value元素相乘，并经过线性变换处理，得到上下文感知的attention value。这项工作的核心贡献在于不牺牲有效的上下文建模能力的条件下，使得Transformer的时间复杂度降至线性，能更好地应用于长输入序列任务。

- (2): 过去的方法主要聚焦在加速Transformer结构，但是它们对长输入序列的操作仍然相对低效，并且其中一些方法在效果上不尽如人意。Fastformer的思路更直接——避开模型中不必要的瓶颈。这篇论文使用加性注意力，而不是像以前的方法使用点积注意力，进一步缩短时间复杂度，并提出一种新颖的全局上下文模型，可以在不耗费大量计算资源的情况下有效地建模长文本输入的上下文。

- (3): Fastformer方法主要包括两大步骤：首先，该方法通过加性注意力机制对全局上下文进行建模，将整个序列的信息提取到一个全局向量中，然后将attention key矩阵与全局向量作元素乘积得到全局上下文感知的key matrix；然后，利用这个key matrix和attention value的元素乘积得到全局上下文感知的attention value，最后将全局上下文感知的attention value与注意力查询向量相加，得到最终的结果。

- (4): 在五个不同的NLP数据集上进行实验，Fastformer在处理长序列时达到了与其它Transformer模型可接近的性能，而且在某些情况下其表现更佳。因此，该方法可以高效地处理长序列和大规模数据集。
7. Methods:

- (1): 本文提出了一种基于加性注意力的高效Transformer模型，命名为Fastformer方法。该方法通过对全局上下文进行加性注意力机制建模替代传统Transformer中仅对token间的交互建模的方法，使用元素相乘的方式学习全局上下文感知的key matrix，最后将全局上下文感知的key matrix和attention value的元素相乘得到全局上下文感知的attention value，最终与注意力查询向量相加得到结果。

- (2): Fastformer方法主要包括两大步骤：首先，通过加性注意力机制对全局上下文进行建模，将整个序列的信息提取到一个全局向量中，然后将attention key矩阵与全局向量作元素乘积得到全局上下文感知的key matrix；然后，利用这个key matrix和attention value的元素乘积得到全局上下文感知的attention value，最后将全局上下文感知的attention value与注意力查询向量相加，得到最终的结果。

- (3): 为了验证Fastformer方法的有效性，本文在五个不同的NLP数据集上进行了实验。实验结果表明，在处理长序列时，Fastformer方法能够达到与其它Transformer模型可接近的性能甚至在某些情况下也有更好的表现。同时，Fastformer方法在时间复杂度上大幅降低，能够更好地处理长输入序列任务。

8. Conclusion:

- (1): 本工作的重要性在于提出了一种基于加性注意力机制的高效Transformer模型——Fastformer，使得Transformer模型的时间复杂度降至线性的同时，不牺牲其有效的上下文建模能力，可以更好地处理长输入序列任务。

- (2): 创新点：Fastformer方法采用加性注意力机制对全局上下文进行建模，代替传统Transformer中仅对token间的交互建模的方法。性能：Fastformer在处理长序列时取得了与其它Transformer模型可接近的性能甚至在某些情况下表现更佳。工作量：Fastformer将时间复杂度降至线性，能够更好地处理长序列和大规模数据集。但该方法可能对于短序列的处理效果不如一些传统的基于点积注意力机制的Transformer模型。
