## Paper:4




1. Title: Is Your Code Generated by ChatGPT Really Correct? (ChatGPT生成的代码真的正确吗？)

2. Authors: Jiawei Liu, Chunqiu Steven Xia, Yuyao Wang, Lingming Zhang

3. Affiliation: University of Illinois Urbana-Champaign (伊利诺伊大学香槟分校), Nanjing University (南京大学)

4. Keywords: Large Language Models, program synthesis, code generation, evaluation 

5. URL: https://arxiv.org/abs/2305.01210, Github:https://github.com/evalplus/evalplus

6. Summary:

- (1): 本文研究了基于Large Language Models (LLMs)直接生成自然语言书写的代码的程序综合。在使用输出输入测试用例的代码评估数据集来衡量各种LLMs在代码综合方面的表现时，测试用例的质量和数量对于全面评估生成代码的功能正确性来说是有限制的。
- (2): 传统方法存在限制，因此本文提出了一种代码综合评估框架EvalPlus。EvalPlus在使用LLM和基于变异的输入生成器产生新的大量测试输入以进一步验证合成的代码。在扩展了HUMANEVAL数据集的基础上，EvalPlus提出了HUMANEVAL+，其是一个通用的代码综合评估框架，能够全面检测LLMs综合的代码的功能正确性。 
- (3): 本文提出EvalPlus，通过自动化测试输入产生生成模型在代码综合过程中的功能正确性。EvalPlus是一种通用框架，可用于评估LLMs的代码生成方法。 
- (4): 在14种流行的LLMs（包括GPT-4和ChatGPT）的广泛评估中，使用HUMANEVAL+测试集，在评估LLM-synthesized代码的功能正确性方面，降低了15.1％的pass@k。例如，CODEGEN-16B的pass@k可以降低超过18.0％，而ChatGPT和GPT-4等商业模型的性能至少可以降低13.0％，这影响了LLMs代码生成方面的所有最新研究的结果分析。此外，本文还发现HUMANEVAL中有几个不正确的实现。作者们开源了EvalPlus、扩增数据集和所有LLM生成的代码，谷仓链接为 https://github.com/evalplus/evalplus，以促进和加速未来的LLM-for-code研究。






8. Conclusion:

- (1): 本研究提出了一种对于Large Language Models（LLMs）直接生成自然语言书写的代码进行综合评估的方法，即EvalPlus综合评估框架。EvalPlus通过自动化测试输入产生生成模型在代码综合过程中的功能正确性，可以全面检测LLMs综合的代码的功能正确性，解决了测试用例质量和数量对于代码综合功能正确性评估的限制问题。该研究具有重要的现实意义，有助于加强LLMs代码生成研究的可靠性和实用性。

- (2): 创新点：研究提出了EvalPlus综合评估框架，解决了传统方法中测试用例质量和数量对于代码综合功能正确性评估的限制问题，促进了LLMs代码生成研究的可靠性和实用性；表现：研究利用评估框架EvalPlus对14种流行的LLMs进行了广泛评估，发现HUMANEVAL中存在几个不正确的实现，并降低了15.1％的pass@k；工作量：研究开源了EvalPlus、扩增数据集和所有LLM生成的代码，有助于促进和加速未来LLM-for-code研究。但是本研究也存在一些不足，如评估框架EvalPlus仍需进一步完善，以提高评估效率和准确性；此外，研究仅基于一个评估数据集，收集更多的数据集有助于深入研究LLMs代码生成的性能和正确性方面的问题。
