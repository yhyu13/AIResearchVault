## Paper:1




1. Title: Large Language Model Guided Tree-of-Thought (基于大型语言模型引导下的思维树方法)
2. Authors: Jieyi Long
3. Affiliation: Theta Labs, Inc. (Theta实验室)
4. Keywords: Large Language Model, Tree-of-Thought, problem-solving, auto-regressive, Sudoku puzzle
5. Urls: Paper - arXiv:2305.08291v1, Github - https://github.com/jieyilong/tree-of-thought-puzzle-solver
6. Summary: 

- (1): 本文的研究背景是大型语言模型有时在长期规划和解决问题的能力上存在局限，需要一种新的方法来改善它们的问题解决能力。
- (2): 过去的方法中，自回归语言模型并没有通过逻辑问题的正确性检查来纠正自己的错误，因此在解决问题时很容易出现错误。为此，本文提出一种受到人类解决复杂问题方式启发的思维树方法，允许自回归语言模型进行回溯来修正错误。此方法在设计上引入了多个模块，包括提示器、检测模块、存储模块和树控制器，以及规定了它们在问题解决过程中的多次对话流程。这种思维树方法自然、灵活，可以很好地规避模型解决问题时的一些局限性，并为模型修正错误提供了更好的可能性。 
- (3): 本文的研究方法是在自回归语言模型中加入基于思维树的模块，运用存储-回溯的机制来进行问题的解决。本文将以数独谜题为例，测试这种方法的有效性，并通过实验结果展示它对于数独谜题解答成功率的显著提升。
- (4): 本文的方法在数独谜题的解答成功率上有明显的提升，能够更好地规避模型解决问题时的一些局限性，且符合作者的研究目标。
7. Methods: 

- (1): 本文提出一种基于思维树的方法来解决自回归语言模型在长期规划和问题解决能力上出现的局限性。该方法受到人类解决复杂问题的方式启发，允许自回归语言模型进行回溯来修正错误。

- (2): 该方法的设计包含多个模块：提示器、检测模块、存储模块和树控制器。其中，提示器指示模型在树结构上的当前位置，检测模块检查语言模型的输出是否符合当前问题和已有知识的逻辑，存储模块用于存储已有的知识和相关信息，树控制器用于控制思维树的生长和缩减。

- (3): 本文的研究方法是在自回归语言模型中加入基于思维树的模块，并引入存储-回溯的机制来进行问题的解决。该方法的流程包括：首先，根据输入问题初始化思维树的根节点和提示器；其次，进行多轮对话，模型通过提示器和检测模块逐步生长出完整的思维树，并在树的各个节点上进行搜索和预测；最后，根据得到的结果，模型进行存储和回溯，更新已有的知识。

- (4): 本文使用数独谜题作为案例，测试了该方法的有效性。实验结果表明，该方法能够更好地规避模型解决问题时的一些局限性，例如不能正确处理问题中的长期依赖关系，同时也显著提升了数独谜题解答成功率。





8. Conclusion: 
- (1): 本文提出了一种基于思维树的方法来解决自回归语言模型在长期规划和问题解决能力上出现的局限性，能够更好地规避模型解决问题时的一些局限性，并为模型修正错误提供了更好的可能性。同时，本文的研究还具有一定的应用价值，可以用于解决类似数独等复杂的逻辑问题。

- (2): 创新点：本文创新地提出了一种受到人类解决复杂问题方式启发的思维树方法，引入多个模块来规划和控制模型的思考和回溯过程，提高了自回归语言模型的问题解决能力。表现：本文通过实验在数独谜题的解答成功率上获得了明显的提升，具有较好的表现。工作量：本文的方法设计复杂，需要引入多个模块并进行多轮对话的模式，存在一定的工作量和计算复杂度。
