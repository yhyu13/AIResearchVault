## 阅读 Pipeline

1. **预读**（周一）：AI 生成 150 字摘要 + 3 个引导问题
2. **精读**（周一晚）：你阅读，标记难点
3. **讨论**（周二）：AI 解释难点，你验证理解
4. **笔记**（周二晚）：整理到本库
5. **复习**（周五）：AI 生成测验，你回答
