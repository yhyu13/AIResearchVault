## Paper:3




1. Title: NANO: Nested Human-in-the-Loop Reward Learning for Few-shot Language Model Control (NANO: 嵌套式人-环-回报学习，用于小样本语言模型控制)

2. Authors: Xiang Fan, Yiwei Lyu, Paul Pu Liang, Ruslan Salakhutdinov, Louis-Philippe Morency

3. Affiliation: Xiang Fan (卡耐基梅隆大学 机器学习系和语言技术研究所)

4. Keywords: Few-shot learning, language generation, distribution control, human feedback, personalization

5. URLs: Paper (arXiv:2211.05750v1), Code (https://github.com/sfanxiang/Nano)

6. Summary:

- (1): 近年来，预训练语言模型在语言生成领域展现出了惊人的能力。但是，在实际应用中，需要控制生成文本的分布以减轻偏差、促进公平性并实现个性化。而现有的控制生成文本分布的技术只能使用量化分布，这些量化分布需要预定义的类别、分布的比例或一个现有的符合期望分布的语料库。然而，许多重要的分布，如个人偏好，是未量化的。因此，本文提出了NANO方法来解决生成按任意（量化和未量化）分布的文本的问题。

- (2): 过去的方法只能处理量化分布，而且需要预定义的类别、分布的比例，或一个现有的符合期望分布的语料库，并且对于未量化分布相对缺乏研究。本文方法从人类反馈中连续学习来解决这个问题，并且在生成阶段引入内部循环来解决缺乏样本的问题。这种方法既能够学习未量化分布，也能够提高量化分布控制的性能。

- (3): 本文提出了Nested Human-in-the-Loop Reward Learning (NANO)，一种小样本可控文本生成算法，它将人类反馈视为一种奖励，并使用基于树的搜索算法和一个嵌套的循环结构来实现小样本学习。这种方法可以持续学习，因此可以逐步掌握未量化分布性质，此外，该方法在少量样本上可实现个性化的生成任务。

- (4): 本文的方法在单一主题/属性控制和定量分布控制方面取得了最优结果，同时也能够在未量化分布控制、个性化方面实现高样本效率。结果表明，NANO是一种有效的方法来控制生成文本的分布性质。
7. Methods: 

- (1): 本文提出的Nested Human-in-the-Loop Reward Learning (NANO)算法的核心思想是将人类反馈视为一种奖励，使用基于树的搜索算法和嵌套的循环结构实现小样本学习。具体来说，该算法是一个基于参考文献中Human-in-the-Loop RL方法的改进版本，增加了嵌套循环结构用于学习量化和未量化分布的控制。

- (2): 在训练阶段，NANO首先从大型语料库中预训练一个语言模型，并接受用户提供的选项和反馈。然后，在为期多个回合的交互中，将人类反馈转换为一个奖励函数，并将其与其他奖励信号结合使用。每个奖励都被编码为一个可解释的指导信号，这有助于模型通过数据自我纠错。

- (3): 在生成阶段，NANO通过内部循环搜索输入token，以控制生成文本的属性。具体而言，对于每个待生成的token，NANO都会通过给定的参考分布和先前生成的token来选择一个条件分布。然后使用指定的奖励函数和文本长度作为约束条件，在通过搜索算法寻优得到的分布下生成下一个token，直到生成文本的长度满足要求并满足分布属性控制要求。

- (4): NANO算法在数据集MNLI、Amazon2和Yelp上测试了其有效性，表明在所提出的任务中NANO算法比现有的方法具有优越性能，并能够在小样本情况下实现个性化生成。





8. Conclusion: 

- (1): 该研究的意义在于提供了一种基于小样本的人-环-回报学习方法，能够实现对文本生成分布的控制，包括量化和未量化分布，进而实现公平性、减轻偏差和个性化等需求。该方法增加了人类反馈的连续学习过程，有望在文本生成领域有更广泛的应用前景。
                     
- (2): 创新点：该研究创新地提出了NANO算法，通过将人类反馈作为奖励信号、引入内部循环结构等方式，实现小样本学习和对文本生成分布的有效控制。性能：该方法在单一主题/属性控制和定量分布控制方面取得了最优结果，同时能够在未量化分布控制和个性化方面实现高样本效率。工作量：该研究在训练过程中需要与人类交互多次，需要人类提供标注和反馈，工作量相对较高。
