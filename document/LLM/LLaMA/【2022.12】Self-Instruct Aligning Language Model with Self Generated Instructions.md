## Paper:161




1. Title: SELF-INSTRUCT: Instruction Tuning LM with Minimal Human-Labeled Data
(自我构建：用人为标注数据最小化地指导LM)

2. Authors: Yizhong Wang, Zhe Gan, Yu Cheng, Jingjing Liu, Jingbo Shang

3. Affiliation: None

4. Keywords: language models, instruction-tuning, fine-tuning, bootstrapping, generative models

5. Urls: paper_url: https://arxiv.org/abs/2212.10560, Github: None

6. Summary:
- (1):该论文的研究背景是要改进预训练语言模型instruction-following的能力。
- (2):过去的方法主要依赖于人类标注的instruction数据，数据储备有限、多样性和丰富性不足的问题限制了模型的泛化能力。本文提出了SELF-INSTRUCT方法，通过bootstrapping算法来降低对标注数据的依赖性。方法的基本思路是从预训练语言模型自身构建instruction-following data，一定程度上提高了数据的多样性和质量。自身构建方法只需要一个种子集合的tasks，在这个基础上通过轮询随机任务和筛选已生成的tasks来构建instruction-following data。自身构建方法的实现方法简单且易于复刻。 
- (3):文章提出的自身构建方法包含三个步骤： 分类，输入输出instance的重建，instance的过滤，可通过交互式的方式进行多次自我构建，降低训练模型对人工标注数据的依赖。方法中关键的模型是预训练语言模型（GPT-3）和其信息抓取API。 
- (4):本文在SUPERNATURALINSTRUCTIONS数据集的测试该模型的效果，结果表明SELF-INSTRUCT完全可以替代目前使用的instruction数据集，且可以获得较好效果。文章提出的方法对于减少对人工标注数据的依赖性具有参考价值。
7. Methods: 

- (1): 本文提出了SELF-INSTRUCT方法，旨在通过自身构建instruction-following data来降低对标注数据的依赖性。具体而言，SELF-INSTRUCT方法包含四个步骤：instruction generation、classification task identification、instance generation与filtering and postprocessing。其中，instruction generation通过自身构建生成新的instruction描述，classification task identification 识别任务是否为分类任务，instance generation 生成对应instruction的输入输出instance，filtering and postprocessing 筛选outliers。

- (2): SELF-INSTRUCT方法中的instruction generation 采用bootstrapping策略，即采用已有的human-written tasks和model-generated tasks来生成新的instruction。此外，分类任务与非分类任务采取了不同的instance generation 策略，分别是input-first approach 和output-first approach。

- (3): 在实现SELF-INSTRUCT方法时，本文采用了GPT-3模型和相应的信息抓取API。在测试阶段，本文使用SUPERNATURAL INSTRUCTIONS数据集进行了实验，结果表明自身构建方法能够显著改善模型的performance，减少对人工标注数据的依赖性。





8. Conclusion: 

- (1): 本文提出了一种基于自身构建方式的 instruction-tuning 方法 SELF-INSTRUCT，旨在通过自身构建的instruction-following data来降低对标注数据的依赖性，从而提升语言模型预测准确性和泛化能力。

- (2): 创新点：SELF-INSTRUCT 方法对于少量标注数据就能达到较好的预测效果，可以减少任务专家和标注者的工作量。SELF-INSTRUCT 方法具有可复现性，不需要采取额外的人为标注。但SELF-INSTRUCT 方法还有框架不够完善，存在一些标注数据的预测错误，需要进一步改进。在特定数据集上结果表现良好，但是否适用于其他领域的预测需要进一步测试。
