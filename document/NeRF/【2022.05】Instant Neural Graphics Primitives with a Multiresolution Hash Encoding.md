## Paper:42




1. Title: Instant Neural Graphics Primitives with a Multiresolution Hash Encoding (多分辨率哈希编码的即时神经图形原语)

2. Authors: Thomas Müller, Alex Evans, Christoph Schied, and Alexander Keller.

3. Affiliation: Thomas Müller, NVIDIA, Zürich, Switzerland.

4. Keywords: Neural Graphics Primitives, Encoding, Hashing, GPUs, Parallel Computation.

5. Urls: Paper url: https://doi.org/10.1145/3528223.3530127 , Github: https://github.com/NVlabs/instant-ngp

6. Summary:

- (1): 本文的研究背景是计算机图形学中的数学函数表示以及神经图形原语的高质量表示方法。

- (2): 之前的方法往往是基于可训练的任务特定数据结构，但是这样的方法有时候过于复杂而且针对性强。 为了提升效率，本文提出了一种可适用于各种任务的多分辨率哈希编码方案，其中多分辨率数据表格还可以避免更新结构操作，避免了闲置的带宽和计算操作。此外，本文的方法实现了全并 CUDA 核心，使得在单个 GPU 上训练高质量的神经图形原语只需要几秒钟。对比实验结果表明，本文提出的方法具有明显的优势。

- (3): 本文提议了一种基于多分辨率哈希编码的新的神经图形原语输入编码。这种编码通过一种自适应，高效的多分辨率哈希表提供了可训练的特征向量的输入，而这些特征向量的值通过随机梯度下降优化。多分辨率结构使神经网络能够消除哈希冲突，从而实现了简单的体系结构，便于现代 GPU 并行计算。本文通过使用经过完全融合的 CUDA 核心实现整个系统，并专注于尽可能减少浪费的带宽和计算操作的实现。

- (4): 本文的方法在四个具有代表性的任务上进行了测试，包括 Gigapixel image、SDF、NRC 和 NeRF。在所有任务中，本文提出的编码及其高效实现都提供了明显的优势：快速训练，高质量和简单性。在各项任务中，采用同一实现和超参数，只有哈希表大小不同以权衡质量和性能。经过实验证明，本文的方法可以在数秒内训练高质量的神经图形原语，并在分辨率为1920x1080时在十毫秒内进行渲染。
7. Methods:

- (1): 本文提出了一种基于多分辨率哈希编码的神经图形原语输入编码方法，该方法利用多分辨率数据表格提供可训练的特征向量输入，并通过随机梯度下降进行优化。

- (2): 本文的方法实现了全并 CUDA 核心，在单个 GPU 上训练高质量的神经图形原语只需要几秒钟。该方法避免了更新结构操作，从而避免了闲置的带宽和计算操作。

- (3): 本文在四个具有代表性的任务上进行了测试，包括 Gigapixel image、SDF、NRC 和 NeRF。实验结果表明，本文提出的方法在如下方面具有明显优势：训练速度快、渲染质量高和算法实现简单。具体来说，采用同一实现和超参数，在不同任务中仅通过调整哈希表大小，本文方法所花费的时间大多在数秒左右，在分辨率为1920x1080时仅需要十毫秒左右进行渲染。

- (4): 本文还通过调整批处理大小，进行了一系列实验来探究不同的参数对 NeRF 收敛速度和质量的影响，结果表明训练从更多的光线（即在批次中加入更多的观察方向）开始训练可以更快地收敛并达到更低的误差。对比实验的结果表明，即使在采用更少的样本数的情况下，本文的方法也能够实现比其他算法更好的收敛速度和质量。





8. Conclusion: 

- (1): 本文提出了一种基于多分辨率哈希编码的神经图形原语输入编码方法，可以快速训练高质量的神经图形原语，并在分辨率为1920x1080时在十毫秒内进行渲染，解决了计算机图形学中数学函数表示和神经图形原语的高质量表示方法问题。该项工作对计算机图形学领域具有重要的学术和应用价值。

- (2): 创新点: 本文提出了一种基于多分辨率哈希编码的新的神经图形原语输入编码，并使用自适应，高效的多分辨率哈希表提供了可训练的特征向量的输入，这种多分辨率结构使神经网络能够消除哈希冲突，从而实现了简单的体系结构，且便于现代 GPU 并行计算，相较于传统的特定任务数据结构方法具有更好的适用性。性能：本文的方法实现了全并 CUDA 核心，在单个 GPU 上训练高质量的神经图形原语只需要几秒钟，并且避免了更新结构操作，因此避免了闲置的带宽和计算操作，具有快速训练和高质量的渲染表现。工作量：本文在四个具有代表性的任务上进行了测试，包括 Gigapixel image、SDF、NRC 和 NeRF，虽然取得了明显的优势，但是仍然在新兴技术研究中处于初期阶段，需要进一步的研究和实验。
