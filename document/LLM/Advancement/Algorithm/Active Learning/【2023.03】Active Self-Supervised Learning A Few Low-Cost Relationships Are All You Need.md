# Positive Active Learning (PAL) 学习策略

## 背景

本文研究的背景是学习数据的表示，这一过程可以用于解决多个任务。

## 方法

本文提出了Positive Active Learning (PAL)学习策略，它通过在自监督学习损失中嵌入已经获得的知识，提供了一种积极有利的学习方式来构建代表数据意义的正样本关系。PAL的关键思想在于将当前未标注的样本与嵌入知识的正样本进行比较，然后选择对模型有最大贡献的样本进行注释，从而减少了注释数据集的成本。

本文将自监督学习和监督学习统一为相似性矩阵的不同形式，并将相似性图形式化作为学习算法的一部分。在实践中，PAL框架可以扩展到监督学习，半监督学习等不同领域。PAL特别适用于自监督学习中的数据增强和迁移学习。

本文提出的PAL方法可以被集成到自监督任务的任何阶段，并开发了一种快速和准确的方法来识别正样本。实验结果显示，与baseline相比，使用PAL方法的模型能够获得更好的性能，证明了PAL方法的有效性和可行性。

## 结论

本文的意义在于提出了一种积极有利的学习策略Positive Active Learning (PAL)，该策略可以在自监督学习中构建代表数据意义的正样本关系。此外，作者还将自监督学习和监督学习统一为相似性矩阵的不同形式，并将相似性图形式化作为学习算法的一部分。本文提出的PAL方法可以被集成到自监督任务的任何阶段，具有较好的适应性与可推广性。PAL方法能够减少注释数据集的成本，因此可以降低数据注释所需的工作量，从而节省人力和时间成本。实验结果表明，基于PAL框架的学习方法在许多不同的任务上表现出了很好的效果，能够获得更好的性能，证明了PAL方法的有效性和可行性。

6. Summary:

- (2): 过去的方法通常使用已知的数据增强来获取正样本，这种方法既不理论上有保证，也不能直观地将标签信息嵌入到现有的自监督损失中。本文提出了在相似图中重新定义自监督和监督损失的方法，提供了一种在自监督学习和有监督学习之间进行无缝切换的方法，同时将标签信息直观地嵌入到自监督损失中。

- (3): 本文提出的方法是基于 积极学习（PAL）的，这种方法是一种主动学习框架，通过查询样本之间的语义关系来构建正样本。同时，通过在相似矩阵上定义损失函数，将得到一个类似于监督学习的可导模型，同时将 label 信息嵌入到模型中得到最优解。 

- (4): 本文的方法在 CIFAR-10，STL-10 和 ImageNet 数据集上得到了表现，与采用标记数据的基线方法相当或更好，表明了这种方法的有效性。
7. Methods:

- (1): 传统的自监督学习方法需要构建已知的语义相关、即正样本的样本，但如何获取这种关系是自监督学习的限制之一。本文提出了一种主动学习的方法来减轻这种困难。具体来说，该方法通过积极学习（PAL）框架查询样本之间的语义关系来构建正样本。PAL是一种主动学习方法，它将自监督任务作为学习的嵌入任务，并使用Active Selection算法（该算法能够在不影响自监督学习性能的情况下查询最有用的样本）实现无监督情况下的主动选择。

- (2): 过去的方法通常使用已知的数据增强来获取正样本，这种方法既不理论上有保证，也不能直观地将标签信息嵌入到现有的自监督损失中。本文提出了在相似图中重新定义自监督和监督损失的方法。具体来说，在样本向量之间构建一个相似度矩阵，并计算出表示样本之间分布的概率分布。然后，通过比较这些概率之间的差异计算自监督损失。监督损失则通过将标签信息嵌入到这个概率分布中得到。

- (3): 通过在相似矩阵上定义损失函数，得到了一个类似于监督学习的可导模型。通过最小化自监督损失和监督损失，得到了在自监督学习和有监督学习之间无缝切换的方法。最后，可以使用传统的有监督学习技术来优化模型，从而得到最终的表示。 

- (4): 为了验证该方法的有效性，本文在CIFAR-10、STL-10和ImageNet数据集上进行了实验。实验结果表明，该方法的表现与使用标记数据的基线方法相当或更好，证明了方法的有效性和可行性。
