## Paper:193




1. Title: A Prompt Pattern Catalog to Enhance Prompt Engineering with ChatGPT（使用ChatGPT增强提示工程的提示模式目录）

2. Authors: Jules White, Quchen Fu, Sam Hays, Michael Sandborn, Carlos Olea, Henry Gilbert, Ashraf Elnashar, Jesse Spencer-Smith, and Douglas C. Schmidt

3. Affiliation: Vanderbilt University（范德堡大学）, Tennessee（田纳西州）, Department of Computer Science（计算机科学系）

4. Keywords: large language models, prompt patterns, prompt engineering（大型语言模型，提示模式，提示工程）

5. Urls: Paper: arXiv:2302.11382v1 Github: None

6. Summary:
- (1):本文的研究背景是大型语言模型，如ChatGPT，已经在各个领域引起了广泛的兴趣，并且提示工程是与之配合的一个越来越重要的技能。
- (2):过去的方法包括给模型传递前缀来获得预测结果，这种方法缺乏灵活性，要求用户有先验知识，并不能充分发挥大型语言模型的优势。本文提出了说明提示模式的提示工程技术，这些提示模式提供了可重用的方法，以解决在特定上下文中面临的常见问题，即利用大型语言模型生成和交互时的输出。本文提供了一个文档框架，用于记录排列提示的模式来解决一系列问题，使其能够适应不同的领域。
- (3):本文提出了一种新的研究方法，采用提示技术来解决机器学习中遇到的各种问题。与传统的机器学习方法不同的是，提示技术允许我们将专业知识和先验知识等因素结合在一起，以便为模型提供更好的输入，从而使模型的预测结果更加准确。
- (4):本文的实验根据提示模式来提高 large language model 的生成能力。结果表明，本文的方法可以显著地提高输出结果的质量以及 model 的效能，支持了其目标。
7. Methods: 

- (1): 本文提出了一个提示模式目录，包含五个大的提示模式类别： 输入语义，输出定制，错误识别，提示改进和交互以及一个上下文控制类别。每个类别都提供了多个可重复使用的提示模式来解决在特定上下文中面临的常见问题，并且本文详细解释了每个提示模式的设计目的、动机、结构和关键思想。
 
- (2): 在方法上，本文采用了一种探索性的研究方法。研究者围绕大型语言模型，通过分析问题的广泛领域，收集了大量的提示模式实践案例，并根据这些案例统计和总结相应的模式命名和结构。研究者使用了模式命名和模式模板，以一种可重复使用并提供有用上下文信息的方式对每个提示模式进行文档化。另外，本文使用自然语言生成技术，构造了多个任务来验证它所提出的大型语言模型提示模式。 

- (3): 此外，本文的评估基于 ChatGPT 的实验表明，提示模式可以有效提高大型语言模型输出的质量和准确





8. Conclusion: 

- (1): 本文提出的提示模式目录为大型语言模型的提示工程提供了一种可重复使用、有效性显著的方法。以此为基础，本文还探索了一种新的研究方法——提示技术，它可以将专业知识和先验知识等因素结合在一起，为模型提供更好的输入，使其输出结果更加准确。

- (2): Innovation point：本文的创新点在于提出了使用提示模式来增强大型语言模型的提示工程技术，并针对特定上下文中的常见问题，提供了一系列可重用的提示模式来解决这些问题。Performance：本文的实验结果表明，使用提示模式可以显著地提高大型语言模型的输出质量和效能，且能够适应不同领域。Workload：本文介绍了大量的提示模式实践案例，并对每个提示模式进行了详细的说明和文档化，这对读者理解和应用该技术是非常有帮助的。但是，本文在实验结果的对比方面还有待进一步的提升。
